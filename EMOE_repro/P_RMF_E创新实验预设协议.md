# P-RMF-E 创新实验预设协议

本协议在查看新模型完整结果前固定。锚点为 `results/dual_baseline_v2/prmf_e/seed_{1111,2222,3333}`；它已与 EMOE 在相同条件下比较，不能再通过附件 3 的无标签预测挑选候选。

## 不变项

- 只读附件 2 `aligned_50.pkl` 的 train=3395、valid=728；Text 50×768、Audio 50×74、Vision 50×35。内部 mask 顺序 L/V/A。`classification_labels` 0/1/2=负/中/正，强度零归中性。
- 使用 `q2_dual_baseline.epoch_mask` 的每样本每 epoch 连续窗口，80% 概率、有效内容 15%–50%、7 种单/双/三模态同段组合；各 seed 的样本顺序也与基线一致。
- batch 16、8 epoch、AdamW `1e-4/1e-4`、AMP、clip 1.0；各 seed 只按 Clean 与 A+V 中段 30% 的同一个复合分数保存 checkpoint。
- 最佳 checkpoint 评估 Clean + 25 个固定缺失场景，报告 Accuracy、Macro-F1、MAE、Pearson、实际新增遮挡率和资源。附件 2 test、附件 3/4 均不参与训练、选择、调参或模型晋升。

## 单因素顺序与停损

1. `mask`：投影后给各模态缺失位置加可学习 128 维 embedding。零初始化，与 P-RMF-E 基线在训练第 0 步完全等价；只新增此项。
2. `coverage`：在原不确定度权重用于跨模态注入之前，加一个可学习标量 `β` 的覆盖率对数修正：`softmax_m(log w_m + β log c_m)`，`c_m` 是有效内容中的观测比例。原 proxy 表征及 VAE 保持不变。`β=0` 初始化；只新增此项。
3. `mask_coverage`：仅在单因素有可信信号时测试组合，不以组合结果掩盖单因素失败。
4. 完整→缺失双头一致性：若前面候选均失败，允许以**独立候选**进行一次单 seed 筛查，因为双基线已显示长 Text 缺失和极端强度的剩余瓶颈；不将失败模块叠入其中。同 seed 冻结的完整输入 P-RMF-E 只在附件 2 train 上产生软目标，教师极性正确且强度误差不超过 0.75 的样本才参与；新增 `0.05×[T=2 分类 KL + SmoothL1 强度]`，原主任务与辅助损失不变。若筛查仍退化，则停止，不实现 CMAD 全套或新的 VAE。

每项先用 seed 1111 做筛查；若 Clean 或缺失网格的 F1 与 MAE出现明显反向退化，则记录失败并停止该项。否则扩展到种子 2222、3333。**晋升门槛**预设为：3 seed 的 25 缺失场景平均 Macro-F1 至少提升 `0.005`、MAE 不升；Clean Macro-F1 下降不超过 `0.005`、MAE 上升不超过 `0.005`；同时分别检查 Neutral 召回与 `|y|≥1.5` MAE，不以单一个别情景的改进替代总体判断。若只有部分指标改进，保留探索结论，不替换 Q2 主交付。

所有数值与同 seed 的基线成对比较；验证集有限，主要候选另给配对 ID 区间。参数/显存/训练时间须记录。零值输入、显式 embedding、coverage 修正及其组合各占一行，不把上述 E 题新增机制写为 P-RMF 原论文方法。
