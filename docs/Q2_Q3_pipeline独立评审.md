## 当前工作流及其合理性

### 问题2

附件2 aligned_50的train/valid → 识别有效内容和源零值 → 在预计算特征上注入连续缺失 → P-RMF-E或EMOE双任务训练 → 按Clean与A/V中段30%的复合验证分数选择checkpoint → 26场景评估 → 冻结模型 → 从附件3给定text_bert重建BERT特征并推理。

P-RMF-E保留三路编码、VAE/proxy、跨模态融合及重建目标，增加三分类输出，直接使用附件2已有文本表示；EMOE保留专家与Router结构，增加双任务及缺失适配。这是对原模型家族的赛题适配比较，不是只替换一个模块的消融，也不是原论文数字复现。

**合理之处：**数据规模与显卡负担匹配；三分类和连续强度定义正确；训练/验证职责清楚；有同seed、同mask、同样本顺序的公平比较；实际新增缺失率、负结果、错误切片和无标签边界均有记录。P-RMF-E在现行协议下确实比EMOE更适合作为Q2起点。

### 问题3

冻结旧EMOE checkpoint → 输出三分类、强度和Router权重 → 各模态按最多4槽分窗并扰动 → 选关键窗 → 整模态消融估计输出敏感度 → 文本offset定位和音视频近似时间映射 → CSV及可视化 → 换干预方式复核。

**合理之处：**并未简单把Router权重等同因果贡献；解释包含模态和局部片段两个层次；保留有符号的输出变化；对缺乏明显贡献或视觉不可观测的样本允许留空。Q2与Q3使用不同主干不违反赛题，只须各自验证并明确说明。统一主干是可维护性和体积上的选择，不是题目硬要求。

可以保留的结论包括：

1. 在当前预算和缺失协议下，P-RMF-E整体优于EMOE；不能推广为所有训练预算、输入版本和单项指标均显著优越。

3. 中性类别、近中性样本和强情感幅度是有证据的薄弱环节；其原因尚未被确定为不可约标签噪声。
4. 现有几个小模块没有达到晋升标准，暂不叠加是合理选择；证据不足以排除同方向的所有实现。
5. Q3关键窗在更换干预方式后仍有输出敏感性。684条合格样本中，donor替换下Top减Random的预测类别概率下降差为0.11186，95%区间[0.09873, 0.12561]；logit margin下降差为0.94906，区间[0.85101, 1.05172]。这项成果应补回工作盘点。

## 必须修正的结论与实现问题

### 1 文本缺失模拟与附件3推理不等价

这是优先级最高的问题。设B为冻结BERT，u为完整词元，M为特征缺失掩码，C为把缺失词元替换为UNK的操作。现有训练和大部分缺失评估使用M·B(u)，而附件3实际入口使用M·B(C(u))。二者一般不相等：BERT表示已经包含双向上下文，重新编码会改变未被遮挡位置的表示。[BERT原论文](https://aclanthology.org/N19-1423/)

代码依据：`missing_protocol.py`只生成特征位置mask；`prmf_e.py`将原text乘mask后编码；`q2_dual_attachment3.py`却先把附件3已有UNK的词元输入BERT，再处理缺失位置。

此次取valid前8条，遮挡中段30%内容词元并替换为UNK，用同一冻结BERT重新编码：

| 检查项 | 平均绝对差 |
|---|---:|
| 完整词元重建与附件2已有text | 0.000000419 |
| 缺失重编码与完整编码，剩余内容位置 | 0.19804 |
| 缺失重编码与完整编码，CLS位置 | 0.17778 |
| 缺失重编码与完整编码，padding位置 | 0.46679 |

这些是表示差异，不是任务性能变化，但足以确认两条数据生成链不一致。旧协议中未删位置可能保留被删内容的上下文信息，导致“局部遮挡不伤性能”的评价偏乐观；这是输入信息残留，不是把验证标签泄漏进训练。

因此，“局部缺失是伪问题”“没有可鲁棒的东西”应改为：**在当前对完整上下文特征进行后置遮挡的协议下，局部删除导致的性能退化较小；对缺失词元重新编码后的结果尚待验证。** 仅换成unaligned_50也不会自动解决文本编码顺序问题。

### 2 padding与真实可观测信息尚未在模型中隔离

`mask_state`把padding排除在缺失统计之外，但仍把它标为observed；P-RMF-E默认分支没有把有效长度传入文本Transformer作为padding屏蔽。此次重算，valid共有17772个文本padding槽，全部是非零BERT向量。CLS、SEP及padding均可能携带完整上下文，不能把它们当作无信息常数。

“统计分母正确”不等于“模型已经屏蔽padding”。在现有权重上临时清零会改变输入分布，出现降分不能证明padding处理没有价值；必须在新旧协议分开的条件下从头训练比较。保留CLS本身没有问题，关键在于其是否由实际可用的词元生成。

同时，E8/E9使用的是第二位agent的简化模型，不是P-RMF-E。该模型的音视频分支是没有显式位置编码的Transformer再均值池化，在推理时对输入行的排列不敏感。不能拿它的结果直接证明复杂时序缺失形态对所有模型都不重要。

### 3 附件3的68%缺失率混入了padding

`deepseek_work/exp/e123_diagnostics.py`统计全部50槽的零行。68.4%是音频全部存储位置的零值比例，报告却把它写成“占有效内容比”。按正文有效内容区间重新统计：

| 项目 | 此次重算 |
|---|---:|
| 全50槽音频零值比例 | 68.4% |
| 有效内容内音频零值比例，逐样本平均 | 20.6745% |
| 有效内容内视觉零值比例，逐样本平均 | 21.0912% |
| 有效内容中出现UNK的样本 | 27/30 |
| 有效内容中有音频零行的样本 | 27/30 |
| 有效内容中音频零段数量，逐样本平均 | 3.1667段 |

故“实际缺失约68%，比训练上限50%更严重”“30/30都缺失”“28/30有UNK”等说法不能沿用。多段缺失和模态同步的现象仍值得研究，但不能再用错误的缺失率推导严重分布偏移，更不能按这个数值重设训练分布。

同理，valid中85条样本有至少一个视觉零内容槽，其中15条视觉内容全部为零，不能把85条都表述为完全没有视觉。

### 4 最新消融报告把4场景均值写成25场景均值

`deepseek_work/exp2/p6_pipeline_verdict.py`的SCEN仅包含Clean和4个缺失场景；第92行的miss实际长度为4，但输出标题和最终md写成了“25场景”。新训练的mask、mask_coverage摘要也只保存这5个场景。

对确实有完整25场景文件的旧变体重算：

| 变体 | 真正25场景ΔMacro-F1 | 真正25场景ΔMAE | 最新报告误标为25场景的ΔMacro-F1 |
|---|---:|---:|---:|
| coverage | -0.00487 | -0.00066 | -0.0114 |
| consistency | -0.00268 | +0.00289 | -0.0028 |

对mask、mask_coverage，现有已查看产物支持“4个缺失场景没有综合收益”，不能宣布已完成原协议的25场景裁决。这里需要补评价，不需要先重训。此错误不推翻“暂不采用这些变体”的工程决定，但必须更正论文中的实验范围和数值。

### 5 温度标定实验无法检验其声称的命题

`p2_ensemble_curve.py`先计算概率均值，再做`softmax(log(Pmean)/T)`。对任意T>0，类别排序不变，所以它与原概率均值的Accuracy/F1完全一样是数学必然，不能据此认定“模型不过度自信”“温度标定无效”。概率校准应评价NLL、Brier、ECE等；若研究校准是否改善集成分类，应先分别校准成员，再聚合，这才可能改变集成类别。[温度标定原论文](https://proceedings.mlr.press/v70/guo17a.html)

另有两处口径问题：所谓wvote实际是按selection加权的概率求和，并非类别投票；`Counter.most_common`平票时依赖成员输入顺序。三分类即使模型数为奇数也可能平票，需明确确定性的平票规则并报告占比。

E3的ECE=0.2359来自旧EMOE输出，却被用来解释P-RMF-E的投票优势；这只能作假设，必须在对应模型概率上重新核验。

### 6 数据上限与统计功效被过度解释

- **0.6676不是可证明的Accuracy上限。** 它建立在近中性区不可分、只能猜多数类的假设上。现模型表现差并不证明输入不含可区分信息；原数据没有提供重复标注分歧来支持不可约误差结论。
- **T到T+A+V增加0.0115不是A/V的贡献上限。** 它仅是特定架构、目标函数和预算下的已实现增量，不能推出增强弱模态不可能有效，也不能严格区分“信息冗余”和“利用不足”。
- **MDE≈0.020不是普遍阈值。** 它由另一个受控台的种子波动粗略计算，不能替代P-RMF-E配对差的方差；样本抽样、训练随机性和多场景相关性也是不同问题。
- E2把P-RMF-E对EMOE的区间宽度，与同一模型缺失对Clean的差值比较，检验对象不一致。应直接对所研究的成对差估计区间。
- 26场景重复使用728条样本，不能当作26次独立验证；多个未校正的显著性检验中出现一个显著结果，不能据此给种子优劣定性。
- “四个变体没有晋升”不等于“想法被普遍否证”。同样，基线逐位复现只证明基线训练链复现，不能证明所有新增变体实现都正确。例：受控台ordinal分支使用两个独立logit后截断非法概率，不是严格保证有序性的CORAL实现。

此次额外检查train/valid的video_id没有交集，官方划分在这个层面做得合理；valid的728条来自239个video_id，后续区间建议采用video_id成组重采样，并单独报告训练seed差异。最终模型冻结后，可使用附件2已有test做一次独立评估，不能再根据该结果回头选模型。

### 7 问题3有独立敏感性验证 但语义解释仍不充分

后续报告说Q3“没有独立验证”不准确。`q3_independent_faithfulness.py`及其report.json证明已经用不同于选窗机制的置零和donor替换验证了关键窗，并排除了无同长度随机替代窗的情形。

还没有解决的是：

1. Router与整模态消融主导模态仅约35%一致。这说明两个量不同，不能把其中任意一个当作无需验证的解释真值。
2. 文本BERT位置承载上下文，删“某个位置的向量”不等于删“这个词的语义”。“It's a”等窗口可能是模型敏感的上下文载体，不能直接说这几个词导致负面判断。
3. 分类证据与回归证据混在`max(0,Δp)+0.1|Δr|/3`里，可能使选中窗口并不支持所展示的分类判断。应分别报告分类margin变化与强度有符号变化，再展示共同证据或冲突。
4. 秒数、帧号目前主要由槽位比例换算，07/18号文本截断会进一步破坏映射；13号视觉全零不能给出有效视觉证据。
5. 划分两半valid并不能单独消除选窗与检验同源，因为每条新样本仍可能用同一种扰动选窗再验证。分割能限制解释超参数调优，真正的独立证据仍来自不同干预、原始素材复核和稳定性检验。

IMTD信任度可作为新的预测可靠性信号，但三个单模态教师的共识不等于旧EMOE实际使用输入的贡献，不能以提高对旧EMOE消融结果的一致率作为唯一目标。`ebd_q3_reliability.py`虽存在，本次未找到其目标JSON；脚本还有NumPy数组链式比较表达式可能在保存前报错，不能把它记为已经完成验证。

| emc | 0.6351 | 0.6015 | 0.5810 | 0.6653 | +0.0101 |
| imtd | 0.6284 | 0.5962 | 0.5898 | 0.6470 | +0.0048 |

EMC的平均方向值得保留，但6个配对seed的F1差，近似t区间为[-0.0080,0.0283]，仍不足以晋升；IMTD存在回归代价；当前两阶段实现明显不利。这些结果不能支持“所有EBMC思想均无空间”，也不支持把EMC直接加入P-RMF-E。

### 9 交付方案尚未闭合

现有正式附件3结果是30样本×2模型×3 seed的180行比较表。9 seed集成的验证实验完成，不等于已经生成最终每样本一行的附件3提交文件；本次在对应exp2目录未见该正式输出。

体积同样需要提前约束：P-RMF-E单个现有checkpoint约31.22MB；按774万参数估计，FP16纯权重约15.5MB，9模型约139MB。Q3旧EMOE的现有FP16文件约45.13MB。即使暂不考虑问题1，直接打包两问现有模型也很难满足总附件50MB。应测量实际压缩包，并考虑单模型、小模型、蒸馏或共享主干；不能把9 seed称为没有代价的最终交付方案。

## 建议的改进顺序

| 优先级 | 具体工作 | 为什么先做 | 可判定的产出 |
|---|---|---|---|
| P0 | 统一数据状态及统计口径；更正68%、4/25场景、Q3独立验证和EBMC完成状态 | 防止在错误结论上继续加模型 | 一份自动生成、绑定模型/seed/场景/指标的证据表 |
| P0 | 冻结现有模型，比较后置特征遮挡与UNK后重编码两套协议 | 验证真正的训练—推理差异；比继续叠模块更直接 | 同样样本、窗口、seed下的性能差，标明这是两种不同退化机制 |
| P0 | 从头对照“旧协议”与“重编码缺失+显式有效位置处理” | 解决输入信息残留及padding处理，而不是在旧权重上临时删信息 | Clean及文本/三模态局部缺失四指标，近中性、长度和强度切片 |
| P0 | Q3建立词元—词—秒—帧映射并人工抽查 | 直接满足关键证据回查要求 | 可核验的映射表；有时间戳依据与近似定位分开，单独处理截断/全零视觉 |
| P1 | 保留简单模型、P-RMF-E和EMOE的同协议比较；分别比较单模型与等规模集成 | 简化模型已有回归优势，复杂主干并非全部指标最优；避免单模型对集成的不公平比较 | Accuracy/F1/MAE/Pearson、训练成本、推理成本和压缩后体积的权衡表 |
| P1 | 为Q3分别定义分类与回归解释，加入原始词元干预和多尺度窗口 | 提升解释的语义对应性，避免两个任务混合评分掩盖方向 | 既有独立干预继续保留；增加词元重编码删除、对照窗及跨seed稳定性 |
| P1 | 用3模态全部8种子集计算交互和边际贡献，比较多种缺失基准 | 单模态整段删除不能拆开冗余与协同；小规模枚举可行 | 条件于所选干预的有符号贡献与交互，不宣称真实因果百分比 |
| P1 | 定义最终预测聚合、平票规则与文件格式；验证压缩/蒸馏后的输出 | 把实验结果转成能提交且可复现的模型 | 附件3每样本一行；附件4预测与解释对应同一实际预测器；总包体积实测 |
| P2 | 再研究模型改进，如任务梯度平衡、损失尺度、轻量融合或较细音视频序列 | 只有数据链和评价口径稳定后，新模块实验才容易解释 | 每次一个假设，等预算、配对seed和主要场景预设，失败保留边界 |

具体执行时还应遵守以下原则：

- 缺失族依据赛题定义预先设置，覆盖单段、多段、单模态及同步组合；附件3只核对接口，不按其经验频率反复调增强或挑模型。不能把整模态删除改为问题2主要任务。
- 在表示协议修正之前，不建议立刻切换unaligned_50。它改变A/V时序长度，增加成本，却不消除文本全句编码后的信息残留；先做小规模同预算验证再决定。
- 损失和分类阈值属于可探索选择，过去小范围失败不足以永久排除；但当前没有理由再次大范围扫同一批方案。优先检查新协议下是否仍有同样的中性/强度瓶颈。
- 校准若只改善概率可信度，也可能有利于Q3的置信描述，不必强求Accuracy同时提高；但不能把校准效果未经检验地写成模态因果解释。
- 如果改用集成或新主干做Q3，必须重新计算其局部扰动和模态贡献。旧EMOE的35%一致率及关键窗验证不能证明新预测器的解释。
- 选择与验证都用过的valid成绩应如实称为开发集结果。冻结数据处理、聚合和解释超参数后，再用已有test做最终独立评估，保留此前全部比较而不重选。

## 推荐保留的研究主线

问题2可以继续沿用P-RMF-E，但研究重点应从“再加一个缺失模块”转向“让缺失发生在正确的信息生成阶段，分清有效位置与缺失位置，并在一致协议下评估鲁棒性”。这是否提高性能需要实测；它首先修复的是实验的有效性。

问题3应在现有扰动解释基础上，把“内部融合权重”“对模型输出的贡献”“能在原始素材中回查的证据”分别定义、分别验证。补上准确映射和原始词元层干预，比仅替换Router权重的公式更贴合题目。

无需推倒现有成果，也无需把“没有独创网络结构”定性为无法交卷。原方法、本题适配、实际改进和负结果应明确区分；合理的数学形式化、可信实验、可复核证据和完整交付本身就是这份工作的核心。
