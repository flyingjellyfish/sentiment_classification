# E 题问题 2、问题 3：refine 前复盘与主干修订

## 双基线完成后的修订结论（2026-09-23）

以下原“三轮复盘”保留对旧 EMOE checkpoint、图表和错误现象的**历史诊断**，其数值不与新 P-RMF-E 直接横比。当前 Q2 主干已经由统一协议的 3 seed 双基线实验改为 **P-RMF-E**，见 [`P_RMF_E与EMOE_Q2双基线对比报告.md`](P_RMF_E与EMOE_Q2双基线对比报告.md)。Clean 验证宏 F1/MAE：P-RMF-E `.6069/.6025`，EMOE `.5818/.6259`；三模态同段 50% 宏 F1：`.5994` 对 `.5719`。Pearson 的成对 bootstrap 区间跨 0，结论限于当前划分与训练预算。

### 对旧诊断的更正与延续

| 原诊断 | 新证据后的处理 |
|---|---|
| 附件 3 只有 A/V 缺失的旧推断 | **撤销。**附件 3 无 `text`、有 `text_bert`；27/30 条有效 Text 区出现 `[UNK]`，与 A/V 零槽高度同步。旧 `q2_aligned.py::infer_special` 仅用 A/V 零值生成 mask，漏掉 Text 已缺失位置。旧附件 3 CSV 的 Text 缺失解释不可靠；正式双基线推理已用三路 mask 且不二次遮挡。审计见 `results/dual_baseline_v2/attachment3_structure.json`。 |
| 原标签讨论 | 统一写为 `classification_labels: 0负/1中/2正`、`regression_labels=0` 是中性。不能把分类编码 0 解释成中性，也不能把连续零并入正向；训练/验证已逐条检查符号映射。 |
| EMOE 22.53M 参数、Router 泛化差距 | 对旧模型仍成立；但不再把“缩小 EMOE Router”列为 Q2 第一优先。已有 64/256 宽 3 seed 消融 F1 基本持平，说明单纯缩容收益未证实。 |
| Neutral 低召回与强度向零收缩 | **继续成立且扩展到 P-RMF-E。**新 Clean 的 Neutral 平均召回 EMOE `.370`、P-RMF-E `.380`；`|y|≥1.5` 的 MAE 分别 `1.198/1.128`。三模态缺失 50% 下 P-RMF-E 极端强度 MAE 上升至 `1.321`，不能只看总体 MAE。 |
| 缺失率、位置异常波动 | 仍须按**实际新增遮挡率**和成对 valid ID 比较。新 26 场景中 P-RMF-E 长 Text 中段 50% 的 F1 比其 Clean 下降 `.0201`，但三模态中段 50% 下降 `.0076`；相对降幅不等于绝对性能排序。 |
| Q3 Router 权重与扰动不一致 | 旧 EMOE Q3 诊断仍有效。未来 P-RMF-E 的 proxy 权重同样仅是模型内部融合权重，须另做时间窗扰动和独立 faithfulness 检查，不得当真实因果贡献。 |

### 修订后优先级与实际执行入口

1. **P0：在 P-RMF-E 上测试显式局部缺失位置 embedding。**与同 seed 原 P-RMF-E 比 Clean、25 场景、Neutral/极端强度及资源；失败即回退零填充。
2. **P1：单独测试 coverage-aware proxy 权重。**原 P-RMF 已有 VAE 方差不确定度，不再从 EMOE Router 重做同一机制；检查权重塌缩与 Text 长缺失。只在独立消融有收益时组合 embedding+coverage。
3. **P1：选择性测试完整→缺失双头一致性。**先保持 P-RMF 的辅助重建/VAE 项不变，明确这是 E 题新增目标；关注 Neutral 与强度收缩，失效即撤销。
4. **P0（Q3 表述）：保留旧 EMOE 解释交付，若改用 P-RMF-E 解释，重新以未参与选窗的干预和视频回看验证。**附件 4 无证据真值；没有可信时间映射前只能把 50 槽索引作为准确定位。

全部创新实验继续只用附件 2 train/valid，保留附件 2 test、附件 3/4 的无标签性质，不作伪标签或引入外部情感数据。下面的旧复盘指标和原“最值得优先处理 5 项”是本次修订的来由，**不再作为 Q2 的执行排序**。

## 第二轮：问题 2 性能、训练日志与分组瓶颈

### 2.1 训练/验证泛化

只读加载各自最佳 checkpoint，在原始 train/valid 上用相同推理口径计算：

| checkpoint | Train Acc / F1 | Valid Acc / F1 | Train MAE / Pearson | Valid MAE / Pearson |
|---|---:|---:|---:|---:|
| clean（第 4 轮） | 0.8981 / 0.8826 | 0.6071 / 0.5779 | 0.4039 / 0.8635 | **0.5992 / 0.6291** |
| augment（第 4 轮） | 0.8404 / 0.8220 | **0.6250 / 0.5950** | 0.4376 / 0.8363 | 0.6182 / 0.6116 |
| full 显式 mask（第 8 轮） | 0.8592 / 0.8418 | 0.6140 / 0.5748 | 0.4077 / 0.8536 | 0.6200 / 0.6162 |
| refined full（第 3 轮，当前 Q2/Q3） | **0.9782 / 0.9755** | 0.6085 / 0.5827 | **0.3114 / 0.9199** | 0.6287 / 0.6088 |

refined 模型的 Train→Valid Acc 差 **0.3697**、Macro F1 差 **0.3928**，MAE 从 0.3114 升到 0.6287，是直接验证的显著泛化差距。训练日志也显示四组训练 loss 大体持续下降，验证指标在最佳轮后波动/回落；不能再仅称为“可能过拟合”。当前模型约 **2253 万参数**，其中 Router 约 **1123 万（49.8%）**，相对 3395 条训练样本很大；“Router 容量促成过拟合”是合理机制假设，尚未通过单因素实验定因。refined 相对 augment 让 A+V 中段 30% 的 F1 从 0.5723 提至 0.5881，却让 clean F1 从 0.5950 降至 0.5827、clean MAE 从 0.6182 升至 0.6287；属于明确的权衡，不是全面改进。

### 2.2 基础误差与四指标

当前 refined 的 valid 为 **Acc 0.6085、Macro F1 0.5827、MAE 0.6287、Pearson 0.6088**。混淆矩阵（真值行、预测列）为 `[[119,39,48],[31,82,71],[39,57,242]]`；Neutral 的召回仅 **0.446**，184 条中 71 条判成 Positive。回归拟合约 `预测=0.451×真值+0.193`，预测范围 `[-2.311,2.371]` 窄于真值 `[-3,3]`；真值 `|y|≥1.5` 的 131 条 MAE **1.126**。因此分类的中性边界与回归的强度收缩是两个不同瓶颈。10 桶 ECE 约 **0.236**：平均最大类别置信度 0.844，准确率仅 0.609；298 条置信度 `>0.95` 中有 71 条错判。

分类和回归是独立输出头，不保证一致。按**仅供诊断、非题目标签定义**的强度中性带 `[-0.25,0.25]` 重映射，验证中有 113/728（15.5%）与分类输出不同；中性带扩大到 `[-0.5,0.5]` 为 186/728（25.5%）。不能用回归值是否**精确等于零**来指控中性预测错误，因为连续回归几乎不会恰好输出零。

**解释结论：**所选窗口影响当前模型输出，这点由遮挡实验支持；它们**未被独立证明**是人类可理解的情感原因。附件 4 的 10 号文本证据 “(umm) And”、16 号 “It's a” 等提示部分窗口偏向模型敏感位置，而非明显情感短语。Q3 CSV 将 Router 权重、整模态正向归一化遮挡量和局部证据分别命名是正确的；当三模态整段遮挡均无明显正向作用时，20 条中 5 条的 `dominant_perturbation_modality=None`，应保留“不确定/无正贡献”而非强行指定主要模态。归一化扰动贡献依赖人为 0.005 阈值，亦不是因果百分比。
