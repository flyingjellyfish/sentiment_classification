## 已完成

1. 新增 `missing_protocol.py`：区分有效内容位、原文件零值和人为连续遮挡，并记录实际新增遮挡率；模型内部统一 L/V/A 顺序。
2. 为 EMOE 添加可关闭的 padding 清零、有效长度池化、有效内容覆盖率 Router 修正；关闭时核对原 checkpoint 的验证输出不变。新增统一训练入口 `q2_staged_refine.py`。
3. 单种子、相同增强与初始化的控制消融：control、padding、padding+pool、覆盖率 Router、冻结 Router、完整教师输出蒸馏，以及轻度类别/强度损失重加权。采用同一 clean+A/V 中段 30% 复合指标选最佳 epoch。padding/覆盖率/蒸馏/重加权均没有得到同时提升 clean 和缺失条件的稳定结果。
4. 从头训练 Router hidden=64 与 256，各 3 个配对种子、8 epoch、相同生成器与选模规则；完成 21 场景缺失网格。64 宽将 Router 参数从 11,226,636 减至 2,806,668（约减 75%），但 clean macro-F1 三种子均值 0.5792 与 256 宽 0.5794 基本相同；A/V 中段 30% 分别 0.5774 与 0.5807。三个配对种子 F1 差正负交错，不能宣称性能胜出。数据见 `results/innovation/scenario_grid.csv`、`multi_seed_summary.json`。
5. 对当前 Q3 关键窗口做独立干预检验：原窗口由缺失 token 遮挡选出；复核改用保持 observed mask 不变的特征置零，以及同预测类别、近似长度的其他样本特征替换。只纳入至少存在一个同模态等长度随机对照窗口的 684/728 条。替换检验的 Top3 减 Random3 预测类别概率下降均值 0.1119、95% bootstrap 区间 [0.0987, 0.1256]；logit margin 下降差 0.9491、区间 [0.8510, 1.0517]。这支持对当前模型的敏感性，不证明人类语义因果。数据见 `results/q3/independent_faithfulness/`。
