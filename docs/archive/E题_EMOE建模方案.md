# E题 EMOE 建模方案

> 状态：建模设计稿，供后续实现与论文方法章节使用；本文不含实验结果。  
> 标记：**〔原论文〕**表示 EMOE 论文或其公开代码已有的做法；**〔E题适配〕**表示为满足赛题或本机条件确定的第一版实现；**〔进一步改进〕**表示需通过消融验证的新增方法。三类内容不可混写为同一项原创贡献。

## 1. 任务边界与数据

| 问题 | 核心任务 | 数据和预期输出 | EMOE 的位置 |
|---|---|---|---|
| 问题1 | 从原始视频提取 Text / Audio / Vision 特征，建立可核验的时间对应关系 | 附件1的100段视频；输出100条时序特征、元数据、对齐示例和复现说明 | EMOE 不负责原始视频特征提取；问题1可以为后续模型提供统一特征方案，但问题2、3可直接使用附件2 |
| 问题2 | 在一个或多个模态的**局部连续时间段**不可用时预测情感极性和强度，分析缺失类型、位置、长度的影响 | 附件2训练/验证；附件3无标签专项测试；输出全量预测 CSV | 以 EMOE 动态融合为基线，增加局部缺失处理 |
| 问题3 | 在三模态完整时预测情感，并说明模态作用与可回看原始素材的局部证据 | 附件2训练/验证；附件4无标签特征与视频；输出全量预测和解释 CSV | 使用 EMOE Router 权重作为模态层线索，另建时间证据定位与核验 |

附件2本地标注表共4850条，包含 train 3395、valid 728、test 727。第一版选 `aligned_50.pkl`；其三路输入为 Text `B×50×768`、Audio `B×50×74`、Vision `B×50×35`。所有标签、预处理统计量、阈值和模型选择只从题目允许的训练/验证数据获得；附件3、4无标签，只做最终推理。本题情感极性为 Negative / Neutral / Positive，连续强度在 `[-3,3]`，真实标签为0时仅属于 Neutral。附件2的 `text` 是预计算的768维文本特征，`text_bert` 是另一种 BERT 输入表示，二者不能当成两种文本模态叠加。

**统一符号。** 后文固定模态顺序为 `(T,A,V)`，分别表示文本、语音、视觉。论文和公开代码多使用 `(L,V,A)`；转换数据和 Router 权重时必须同步重排，避免把语音、视觉权重错位。`B` 为批量大小，`T=50` 为存储序列长度，`d=256` 为第一版统一隐藏维度。

## 2. 整体技术路线

```text
问题1：100段视频 + 转写文本
  → 音视频解码与时间戳
  → 三模态特征提取
  → 跨模态时间映射、有效长度与填充记录
  → 100条可追溯时序特征

问题2：附件2有标签特征
  → EMOE-E 基线训练
  → 训练阶段模拟局部连续缺失
  → 缺失感知编码与 Router
  → 验证集鲁棒性分析
  → 附件3预测

问题3：附件2有标签特征
  → EMOE-E 基线或与问题2共享的编码器
  → Router 模态权重 + 时间级证据评分
  → 原始视频/文本回看核验
  → 附件4预测与解释
```

**阶段关系。** 问题1与后两问在研究主题上递进，但不应把“问题1生成的特征必须训练问题2、3”写成题目要求。问题2和3可共用同一个 EMOE 基线与数据接口；专项扩展、评价和结果文件分别组织。

## 3. 问题1：特征提取与时序对齐

**〔E题适配〕输入与输出。** 输入为附件1的 `video_id/clip_id.mp4` 和对应 `text`、`label`、`annotation`。对全部100条样本保持 `video_id + clip_id` 唯一对应，不修改原始素材及标签。输出每条样本的文本、语音、视觉特征序列，以及原始视频时长、各模态有效长度、时间映射、填充位置、工具版本和处理日志。

第一版可选50个统一序列位置，便于与附件2的对齐版接口相接；**50是本方案的设计选择，不是问题1强制要求**。建议的处理顺序为：

1. 从视频提取音轨、画面及各自时间戳；保留原视频时长和解码异常记录。
2. 使用题目给定的英文转写文本。将词或词元与语音时间对齐；无法可靠对齐时记录失败及所用的回退规则，不编造精确时间戳。
3. 文本可由 `bert-base-uncased` 生成上下文表示；语音可采用 COVAREP 类特征，视觉可采用面部动作单元/表情特征提取器。`768/74/35` 是与附件2兼容的目标维度；若实际提取器不同，必须记录真实维度与提取方法，不能把不同语义的特征仅靠补零冒充附件2特征。
4. 将语音帧、视频帧按实际时间戳映射到统一位置；文本位置记录对应词元和时间区间。每个模态显式保存有效掩码与填充规则。
5. 汇总100条结果，选至少1条展示“文本片段—语音时段—视频帧段—特征位置”的对应关系。极短或异常样本仍保留，并说明处理规则。

问题1输出可以帮助解释原始信号与序列位置的关系。若问题3使用附件4的原始视频，还需对附件4**另行建立或核验**相同类型的时间映射；附件2、4的预计算数值特征本身不提供逐词时间戳。

## 4. EMOE-E 第一版基线：从输入到双任务输出

**定位。** EMOE 原论文的核心是 *Mixture of Modality Experts*（每个样本的动态模态权重）、单模态预测辅助、Router 平衡和单模态蒸馏。以下 `EMOE-E` 保留这些思想，并为本题双任务、填充位置与16GB显存设计一个可直接实现的版本。它不是“逐行复刻论文公开代码”；差别见第4.7节。

### 4.1 张量总览

| 阶段 | Text | Audio | Vision | 目的 |
|---|---|---|---|---|
| 输入 | `B×50×768` | `B×50×74` | `B×50×35` | 附件2对齐版预计算特征 |
| Projection | `B×50×256` | `B×50×256` | `B×50×256` | 统一特征维度 |
| Unimodal Encoder | `B×50×256` | `B×50×256` | `B×50×256` | 学习各自时序上下文 |
| 有效位置池化 | `B×256` | `B×256` | `B×256` | 形成样本级模态向量 `z_T,z_A,z_V` |
| Router | \- | `concat(z_T,z_A,z_V): B×768 → B×3` | \- | 输出 `w_T,w_A,w_V`，各样本权重和为1 |
| Dynamic Fusion | \- | `z_f: B×256` | \- | 样本级融合表示 |
| 输出头 | \- | 分类 `B×3`；回归 `B×1` | \- | 极性与强度 |

主干 pipeline：

```text
Input (B×50×768 / 74 / 35)
  → Projection (三路 B×50×256)
  → Unimodal Encoder (三路 B×50×256)
  → Masked Pooling (三路 B×256)
  ├→ Router: concat B×768 → B×3
  ├→ Unimodal Heads: 每路 B×3 与 B×1
  └→ Dynamic Fusion: B×256
       → Classification Head: B×3
       → Regression Head: B×1
```

### 4.2 Projection：统一维度

**〔原论文〕** 文本、语音、视觉先经过各自的 1D temporal convolution，再进入各自的编码器。公开代码中 MOSEI 的卷积核宽度为 Text 5、Audio 1、Vision 3，且没有保持原长度的 padding。

**〔E题适配·第一版〕** 为统一张量和有效掩码，三路各用 `Conv1d(kernel_size=1, in_channels=d_m, out_channels=256)`，等价于逐时间位置的 Linear；再做 LayerNorm 和 dropout。计算时先将 `B×50×d_m` 转为 `B×d_m×50`，卷积后转回 `B×50×256`。核宽度1不改变长度。该层解决三路输入维度不同的问题；若后续恢复原论文卷积核，应同步重算输出长度与掩码。

### 4.3 Unimodal Encoder 与样本级特征

**〔原论文〕** 各模态使用独立的时序 Transformer 提取高层特征；公开代码配置为4层、隐藏维度256、8个注意力头，取编码序列的末位置作为模态向量。

**〔E题适配·第一版〕** 三个独立的 `TransformerEncoder`，每路4层、`d_model=256`、8 heads、FFN 1024、dropout 初始0.1。输入/输出均为 `B×50×256`。用有效位置掩码屏蔽 padding，并对非 padding 位置做 masked mean pooling：

`z_m = Σ_t P[m,t]·H[m,t] / max(1, Σ_t P[m,t]) ∈ R^(B×256)`。

这里 `P∈{0,1}^(B×50)` 标识原始有效位置。采用 masked pooling 是因为有效序列通常短于50，直接取第50位可能取到填充区；它是本方案对公开代码的适配，不应写成原论文原式。三个 Encoder 不共享参数，以保留模态差异。

### 4.4 Router：每条样本的模态权重

**〔E题适配·第一版〕** 将三个样本级向量按固定 `(T,A,V)` 顺序拼接：

`r = [z_T;z_A;z_V] ∈ R^(B×768)`。

采用轻量 Router：`Linear(768,256) → GELU → Dropout(0.1) → Linear(256,3) → softmax(logits / τ)`，先取 `τ=0.1`，仅在验证集调节。输出 `W=[w_T,w_A,w_V]∈R^(B×3)`，每行非负且和为1。例如某样本可得到 `(0.58,0.27,0.15)`；这些是**模型分配的融合权重**，不能单独证明因果贡献。

Router 必须只使用输入特征；训练时由真实标签计算的“模态能力目标”仅进入损失，不能作为推理输入。Router 为每个样本单独给权重，是 EMOE 相比固定权重融合的关键。

### 4.5 Dynamic Fusion 与双任务预测头

**〔原论文〕** 默认使用 Router 权重对三路特征加权求和，也比较了加权拼接。

**〔E题适配·第一版〕** 对 `B×256` 的样本级向量做：

`z_f = w_T[:,None]·z_T + w_A[:,None]·z_A + w_V[:,None]·z_V ∈ R^(B×256)`。

实现广播时，将 `w_T = W[:,0]` 的 `B` 维扩展为 `B×1`，其余模态相同，再逐元素乘 `B×256`。若在时间序列上加权，权重需扩展为 `B×1×1` 与 `B×50×256` 相乘；第一版融合发生在样本级向量上，不混用这两种形状。

**〔E题适配〕** 从 `z_f` 分出两个独立任务头：

- 分类头：`LayerNorm(256) → Linear(256,128) → GELU → Dropout(0.1) → Linear(128,3)`，输出 `logits_cls∈R^(B×3)`，列顺序固定为 Negative、Neutral、Positive。
- 回归头：同样的 `256→128→1` 结构，输出 `r_hat = 3·tanh(raw)∈R^(B×1)`，保证预测值位于 `[-3,3]`。这一步属于赛题适配，原论文主预测是连续情感强度。

三路 `z_m` 也各接独立的分类头和回归头，得到 `(logits_cls,m, r_hat_m)`。这些单模态头用于训练单模态能力、构造 Router 平衡目标和蒸馏；最终提交使用融合头的两项输出。分类与回归来自各自的头，不强制把回归值取符号代替三分类；验证时检查两头不一致样本并在论文中说明。

### 4.6 损失函数：原方法与双任务适配

设 `y_cls∈{0,1,2}`、`y_reg∈[-3,3]`。对融合头使用：

`L_cls = CE(logits_cls, y_cls)`；`L_reg = mean(|r_hat - y_reg|)`；`L_fused = L_cls + λ_reg·L_reg`。

**〔原论文〕** 原任务对融合预测和三路单模态预测使用 MAE；Router 平衡由熵项与“权重—模态能力”相似项组成，并加入单模态蒸馏。论文实验中平衡项和蒸馏项的外层系数均取0.1，相似项系数 `α=0.1`。公开代码以单模态预测平方误差的归一化倒数构造能力权重，以均方误差约束 Router；其实现细节与论文公式中写出的 softmax 形式不完全一致。

**〔E题适配〕** 对每个模态定义 `L_m = CE(logits_cls,m,y_cls) + λ_reg·mean(|r_hat_m-y_reg|)`，再令 `L_uni=(L_T+L_A+L_V)/3`。训练时可按样本计算模态误差 `e_m`，以 `q_m ∝ 1/(stopgrad(e_m)+ε)` 归一化得到能力目标 `q∈R^(B×3)`；第一版固定 `ε=0.1`。`q` 只用于训练，不在无标签测试样本上计算。为避免分类与回归数值尺度失衡，`λ_reg` 只由验证集确定，并在所有对照实验中固定。

Router 平衡项采用：

`L_ent = mean_B[3·Σ_m w_m log(w_m+ε)]`，最小化该负熵项可抑制权重过早坍缩到单一模态；

`L_sim = mean_B Σ_m(w_m - stopgrad(q_m))² / 3`，使 Router 权重参考单模态实际预测能力；

`L_balance = L_ent + α·L_sim`，第一版 `α=0.1`。

蒸馏需设**独立投影**，否则若直接拿 `z_f=Σw_m z_m` 与同一加权和比较，损失恒为零。令 `u_f=g_f(z_f)∈R^(B×256)`，`u_m=g_m(z_m)∈R^(B×256)`，每个 `g` 为独立的 `256→256` 投影。定义：

`u_teacher=stopgrad(Σ_m w_m·u_m)`，`L_ud=MSE(softmax(u_f), softmax(u_teacher))`。

**〔原论文代码的实现方向〕** 单模态组合被 `detach`，融合投影承担蒸馏梯度；论文第(11)式的箭头表述与代码的梯度方向不一致。第一版按代码方向实现，并在论文中说明采用的定义。

最终可写成用户所需的双任务形式：

`L_total = L_cls + λ₁·L_reg + λ₂·L_EMOE`，

`L_EMOE = L_uni + β·(L_ent + α·L_sim) + γ·L_ud`。

初始取 `λ₁=1、λ₂=1、β=0.1、α=0.1、γ=0.1`，随后只用验证集调整。`L_cls` 对应极性、`L_reg` 对应强度、`L_uni` 维持各模态的可预测性、`L_balance` 约束权重学习、`L_ud` 让融合表示保留单模态预测信息。各项训练日志须分别记录，防止某项尺度异常掩盖主任务。

### 4.7 与原论文/代码的明确差别

| 项目 | EMOE 原论文或公开代码 | 本方案第一版 |
|---|---|---|
| 主任务 | 以情感强度回归为主，并据其评价 ACC-7、ACC-2、F1、MAE | 独立三分类头与强度回归头，按 E题评价 Accuracy、F1、MAE、Pearson |
| 输入 | 原代码默认 `use_bert=true, use_finetune=true` | 优先使用附件2已给的 `text:50×768`，不在线微调 BERT，以适应16GB显存；属于硬件与数据适配 |
| 卷积 | MOSEI 核宽 Text/Audio/Vision 为5/1/3，无 same padding | 三路核宽1，保持50步；可在复现实验中另测原核宽 |
| 样本级向量 | 公开代码取 Transformer 末时间位置 | 对有效位置 masked mean pooling，避免取到 padding |
| Router | 公开代码先将对齐后的原始序列展平，再经大维度线性层输出3权重；对齐版输入约 `50×(768+74+35)=43850` 维 | 三个256维样本向量拼成768维，再经小型 MLP 输出3权重；降低显存与参数量 |
| 蒸馏 | 公开代码对融合投影与加权单模态投影做 softmax 后 MSE，单模态侧停止梯度 | 保持同一梯度方向，但显式规定独立投影和双任务监督 |

因此，应将第一版实验命名为 **EMOE-E 基线**。若要报告“严格复现原论文”，必须另跑原输入、原 Router、原卷积、原取值方式和原任务定义；不能把本方案适配后的结果称为论文数值复现。

## 5. 问题2：局部连续缺失的鲁棒改进

### 5.1 Temporal missing mask 与模拟

**〔进一步改进〕** 对每个模态分别维护两个 `B×50` 布尔掩码：`P_m` 表示样本真实有效位置，`O_m` 表示该位置是否观测到，`M_m=P_m∧O_m` 才能参与编码和池化。这样可区分“原始 padding”与“有效范围内的缺失”。附件3中连续全零区间可能表示缺失，但末尾全零也可能是 padding；需结合有效长度或附件字段判断，不能简单把所有零行都当缺失。

训练阶段在 `train` 的有效位置内随机选择模态、起点和连续区间长度，将该段观测掩码置0并将对应特征置0。验证集按预先固定的种子和缺失方案评价：模态类型、位置（前/中/后）、持续长度或缺失率分组。保留无缺失验证结果，避免只优化缺失场景而损害完整输入性能。专项附件3不参与训练、调参或阈值选择。

### 5.2 Missing-aware Encoder 与 Router

**〔进一步改进·第一版〕** Projection 后以可学习的 `missing_token_m∈R^256` 替换缺失位置表示；Transformer attention 使用有效位置 `P_m` 作为 padding mask，同时把 `O_m` 作为额外状态嵌入，使网络能区分观测值与缺失占位。最终只对 `M_m=1` 的位置池化，得到 `z_m∈R^(B×256)`；无观测位置的模态使用零向量和覆盖率0，Router 可将其权重屏蔽。

覆盖率 `c_m=Σ_t M_m,t / max(1,Σ_t P_m,t)`，三路拼成 `c∈R^(B×3)`。缺失感知 Router 输入由 `B×768` 增为 `[z_T,z_A,z_V,c_T,c_A,c_V]∈R^(B×771)`，网络 `771→256→3→softmax`。这让 Router 同时看到内容和可用比例；当某模态完全没有有效观测时，对应 logit 在 softmax 前屏蔽。**问题2规定的重点仍是局部缺失，完全不可用只作为安全回退，不作为主要实验设定。**

第一版先不加特征生成器。可用覆盖率和 Router 权重记录样本级置信线索，并按缺失率分析误差。若消融表明大段缺失仍是主要瓶颈，再尝试在训练集上增加局部重建辅助损失；重建只能使用当前样本可观测内容和题目给定训练数据，且必须与“不重建”的简单方案公平对照。

问题2完整 pipeline：

```text
附件2训练样本 B×50×(768/74/35) + P
  → 连续区间缺失模拟，得到 O、M
  → Projection，三路 B×50×256
  → Missing-aware Encoder，三路 B×50×256
  → M-masked pooling，三路 B×256
  → Router([三路向量, 覆盖率])，B×771→B×3
  → 加权融合 B×256
  → 分类 B×3 + 回归 B×1
  → 附件3全量推理与分组鲁棒性分析
```

## 6. 问题3：可解释性预测方案

### 6.1 模态层解释

**〔原论文〕** Router 为每个样本输出三模态权重；论文用这些权重展示样本间模态重要性差异。

**〔E题适配〕** 以 `W=(w_T,w_A,w_V)` 作为**模型内部的模态层重要性报告**，例如 `Text=0.58, Audio=0.27, Vision=0.15`，并报告最大者为“主要参考模态”。三项权重和为1。权重只表示当前模型如何分配融合比例；单独的高权重不构成该模态真实致因的证明。可补充模态遮蔽前后的输出变化，检查权重与预测敏感度是否一致。

### 6.2 时间级证据：先定位，再核验

**〔进一步改进·第一版〕** 保存 Encoder 的 `H_m∈R^(B×50×256)`。对每个有效位置或短连续窗口计算时间证据分数。可先用梯度 saliency `||∂s/∂H_m,t||` 快速筛选，再用**扰动验证**确定最终证据：只遮蔽该模态的一小段，比较原预测与遮蔽后预测。分类可比较原预测类别的概率下降，回归可比较强度预测的变化绝对值。窗口大小、步长和 Top-K 数量只在验证集确定；不同模态分别归一化，排除 padding 和原本缺失位置。注意力权重可以用于展示或候选筛选，但不直接等同于可靠解释。

输出字段至少包括：样本 ID、三分类概率与类别、强度预测、三模态权重、主要参考模态、每个模态的 Top-K 序列区间及其重要度；再把序列区间映射到可回看的原始证据：

- **Text**：词或短语及其在转写文本中的位置；
- **Audio**：起止秒数和对应音频片段；
- **Vision**：起止秒数、帧号或关键帧区间。

附件4给出原始视频和 `raw_text`，但预计算特征不自动给出每个序列位置的精确秒数。因此须对附件4建立“序列位置→原始时间”的额外映射，例如结合转写文本、音频强制对齐、帧时间戳与人工抽查。若某位置只能近似映射，应在解释结果中标注定位精度；**不能直接把 `t/50×视频总时长` 当作已经验证的精确证据**。典型样本解释卡至少展示预测、权重、Top-K 证据和原始素材回看结果。

问题3完整 pipeline：

```text
附件4完整三模态特征 B×50×(768/74/35)
  → Projection，三路 B×50×256
  → Unimodal Encoder，三路 B×50×256
  → masked pooling，三路 B×256
  → Router，B×768→B×3（模态层解释）
  → Dynamic Fusion，B×256
  → 分类 B×3 + 回归 B×1
  → 时间 saliency/局部扰动，三路 B×50 或窗口级得分
  → 序列位置映射原始文本、音频时段和视频帧
  → 预测与解释 CSV
```

## 7. 训练、验证和实验设计

1. **数据协议。** 固定 aligned 第一版，按附件2既定划分；训练集用于拟合，验证集用于超参数、阈值和最佳 checkpoint 选择。附件2 `test` 若用于内部一次性评估，不参与任何模型或阈值选择。附件3、4只用于各自专项最终推理。若改用 unaligned，训练/验证/专项测试需整套切换，不能混用特征版本。
2. **先跑最小基线。** 先训练完整输入上的 EMOE-E 双任务模型，核验损失下降、权重和为1、输出范围、分类标签顺序、有效掩码。之后分别加入问题2缺失模块、问题3证据模块，避免无法定位改进来源。
3. **优化设置。** 论文使用 RTX 4090 24GB、batch 16，并报告50轮训练；公开代码用 Adam、验证集选模和 early stopping。本机核验为 RTX 5060 Ti 16GB。先以预计算 `text`、batch 16、混合精度试运行并记录峰值显存；不足则降至8或4，用梯度累积维持有效 batch，记录实际优化设置。这是硬件适配，不视作原论文设置完全一致。
4. **指标。** 极性：Accuracy、F1（建议明确报告 macro-F1，同时可补 weighted-F1 与混淆矩阵）；强度：MAE、Pearson。评估脚本明确 `label=0 → Neutral`，不得让零同时进入正负类。报告各类样本数、验证集性能与错误归因。
5. **消融。** 至少比较固定平均融合、仅 MoME、仅单模态辅助/蒸馏、完整 EMOE-E；问题2依次加入连续缺失训练、missing-aware encoder、missing-aware Router，并按缺失类型/位置/比例分组；问题3比较仅 Router 权重、加时间 saliency、加扰动核验。消融保持同一数据划分、训练预算和评价脚本。
6. **可复现性与提交。** 固定随机种子、预处理参数、缺失模拟方案、模型配置和最佳 checkpoint 规则；保存训练曲线、各损失项、验证指标与示例解释。提交附件总量须满足赛题的 `≤50MB` 要求，且不得包含单位、队员或队伍编号等身份信息。论文原 MOSEI 使用约2.29万条数据，本题附件2仅4850条，不能用论文表格数值作为本题应达到的分数。

**专项输入接口检查。** 本地抽查发现附件3单文件是 `{'test': {...}}` 包装，且对齐/未对齐样本的文本字段不完全等同于附件2主文件：抽查对齐样本有 `text_bert`，未对齐样本有 `raw_text`，未直接提供预计算 `text`。因此，若 EMOE-E 用附件2的 `text` 训练，必须在最终推理前为附件3设计**同源、固定且不使用测试标签**的文本表示转换，并验证维度与分布；不能直接假定所有专项文件都含 `B×50×768`。附件4抽查样本有 `text`、`audio`、`vision`，仍需按文件实际字段逐项验证。接口转换只处理题目提供样本，不引入外部情感数据集。
