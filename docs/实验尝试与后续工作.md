# Q2/Q3 实验尝试与后续工作

本页合并历次模型探索、失败案例和后续方向。**正式交付模型只有原 P-RMF-E 三种子集成**：`1111/2222/3333` 的 `dual_baseline_v2/prmf_e/seed_*/best.pt`。Q2 和 Q3 使用同一组权重；其他变体均是消融，不作为最终预测器。完整论文方法与结果见[论文手工作报告](Q2_Q3_论文手工作报告.md)，Q3 实际解释流程见[技术说明](../EMOE_repro/Q3_PRMF_E_README.md)。

## 固定结论与口径

- 数据只用赛题附件 2 `aligned_50` 训练与有标签验证；附件 3/4 无标签。分类 `Negative/Neutral/Positive`，强度 `[-3,3]`；标签 0 仅指 Neutral。
- 原三模型集成在附件 2 **Clean valid** 的 Acc/Macro-F1/MAE/Pearson 为 **`.6580/.6289/.5873/.6419`**。平票按平均类别概率破局，回归取三个截断输出的均值。旧 `.6593/.6287` 来自另一种平票实现，不是模型能力的额外提升。
- 25 个局部连续缺失场景在较严格的 **Text 词元先 `[UNK]`、冻结 BERT 重编码**协议下，集成均值为 **`.6283/.5937/.6043/.6179`**。后置 BERT 特征遮挡的旧场景数值更高，两种协议不混比。
- 完整 valid 3 类召回约 `.7476/.4076/.7396`；中性样本最难。长 Text 连续缺失显著降低 Macro-F1。附件 3 30 条存在同段 Text `[UNK]` 及 A/V 零槽，推理时不额外遮挡。
- 附件 4 的 Q3 全量 20 条由同一集成预测。proxy 权重近乎均匀，故主要参考模态以整模态扰动定义；时间窗以匹配随机窗和 donor 替换检验。解释是模型敏感性，不宣称语义因果真值。

## 后续工作

1. 若继续研究，优先改善 **长 Text 缺失时 Neutral/Negative 的召回权衡**，新候选必须在同一 `[UNK]` 协议、三 seed、Clean + 25 条件下同时报四指标与逐类召回，再和同规模集成比较。
2. 考虑训练期的 Text 连续缺失视图与观测置信度；每次只加一个轻量模块，记录新增参数和时间。已有简单分支的平均收益不足以支持部署。
3. Q3 解释应补原视频人工核验；音视频目前只能准确定位 `aligned_50` 槽，秒数/帧号是均匀插值近似。
4. 比赛提交总附件约 50 MB；三份 FP32 权重合计约 89.3 MiB。若需正式提交，须另测单模型或量化权重的性能及预测一致性，不能把仓库中的三模型集成直接称为满足提交体积限制。
