# E 题问题 2、问题 3：论文手精简工作稿

> 版本：2026-09-24。本文只写已经实现和验证的方案。Q2 的 P-RMF-E 与 Q3 的 EMOE 是**两个已训练模型**；新一轮文字缺失增强是 Q2 实验候选，尚未替换正式主干。数值均来自题方附件 2；附件 3/4 无标签，不计算准确率。

## 1. 问题背景与任务

赛题研究视频中的文本、音频、视觉三模态情感。**问题 2**要求在一个或多个模态的**局部连续时间段**缺失时，仍预测三分类极性（Negative / Neutral / Positive）和连续强度 `[-3,3]`，并分析缺失类型、位置、比例和时长的影响。**问题 3**要求在预测之外说明模型主要使用哪种模态、哪些文本片段、音频时段和视觉帧区间，并验证解释是否反映模型行为。两问可使用题方已对齐特征；问题 1 的原视频特征提取不属于本文已完成工作。

统一使用附件 2 `aligned_50`：train/valid/test 各 `3395/728/727` 条，Text `B×50×768`、Audio `B×50×74`、Vision `B×50×35`。`text_bert` 为词元 ID、attention mask、segment ID，维度 `B×3×50`；有效长度用于区分内容和 padding。三分类由强度标签定义：`y<0` 负、`y=0` **仅中性**、`y>0` 正。附件 3 的 30 条和附件 4 的 20 条都无标签，只用于最终推理与展示；不引入其他情感数据集。

## 2. 总体建模路线

```text
附件 2 aligned_50 → 三模态有效位置和已有缺失 mask
  ├─ Q2：连续缺失增强 → P-RMF-E 编码/代理融合 → 分类 B×3 + 回归 B×1
  │       └─ 同协议比较 EMOE；另测文字 [UNK] 重编码和中性加权候选
  └─ Q3：完整输入 → 冻结 EMOE 分类/回归 + Router 权重
          → 整模态遮挡与局部窗扰动 → 模态作用与时间级证据
```

**缺失协议是实验的关键。**原公平双基线在完整 BERT 特征上后置遮挡 Text，即 `M⊙B(u)`；附件 3 的文字缺失更接近先把词元换成 `[UNK]`、由冻结 BERT 重编码，再遮挡缺失槽，即 `M⊙B(C(u))`。两者不等价。下文将旧双基线与新协议候选分表报告，不直接比较两套缺失场景的绝对成绩。Audio/Vision 在缺失槽使用零特征与观测 mask；验证中的人工缺失是连续窗口，附件 3 已有缺失，推理时不再额外随机遮挡。

## 3. 模型和模块设计

### 3.1 Q2：P-RMF-E 主干

P-RMF-E 保留 P-RMF 的代理模态与不确定度融合结构，并为赛题改为 50 步连续三模态输入、局部连续缺失训练和极性/强度双头。它是**E 题适配版**，不是 P-RMF 原论文训练流程的逐行复现。

| 模块 | 主要运算与维度 | 作用 |
|---|---|---|
| 输入与缺失 | `T:B×50×768`，`V:B×50×35`，`A:B×50×74`；观测 mask `B×3×50`，代码顺序 T/V/A | 区分有效内容、原有零行和人工连续缺失 |
| 三路编码 | 各模态线性投影到 128 维，加入 8 个可学习 token；2 层、8 head Transformer；每路取 `H_m:B×8×128` | 把不同维数、50 步序列压到统一 token 表征 |
| 代理与不确定度 | 每路 VAE 估计 `μ_m,logσ²_m:B×8×128`；不确定度权重 `W:B×3×8×128`；加权代理 `P=Σ_m W_m⊙μ_m:B×8×128` | 用可观测模态构造代理表征，权重按样本/token/通道变化 |
| 跨模态融合 | 代理查询三路模态特征；加权注入和残差输出 `B×8×128`，token 均值池化得 `z:B×128` | 汇合三模态信息，允许局部缺失条件下预测 |
| 双任务与辅助目标 | `z→B×3` 分类 logits、`z→B×1` 强度；另有 token 重建与 proxy/VAE 辅助损失 | 同时完成极性、强度和不完整输入表征学习 |

原 Q2 目标为 `L=CE+L1+0.1L_rec+0.5L_proxy`。`L_proxy` 包含代码中的 VAE 重建/KL 和模态间项，论文不能简写成单一标准正态 KL。训练使用 `1111/2222/3333` 三种子、8 epoch、batch 16、AdamW `1e-4`、AMP；每个 seed 按 Clean 与 A/V 中段 30% valid 的预定复合分数选 checkpoint。EMOE 在同划分、mask、预算下作 Q2 对照。

### 3.2 新一轮 Q2 轻量候选：真实文字缺失与中性加权

先在训练增强窗口中把缺失 Text 词元改成 `[UNK]`，经过**冻结** BERT 重新得到 `B×50×768`，然后仍按观测 mask 置零；完整 Text 特征继续作为辅助重建目标。最终候选只在**Text 内容缺失**的样本上清零有效长度之后的 padding 输入，并在其真实类别为 Neutral 时把分类 CE 的样本权重设为 `1.5`：

`L_cls = Σ_i α_i CE(s_i,c_i)/Σ_i α_i`，其中 `α_i=1.5` 当且仅当训练样本发生 Text 内容缺失且 `c_i=Neutral`，其他样本 `α_i=1`。其余损失和主干不变，不增加参数。这里清零的是输入 padding 特征，**不是** Transformer 的 attention padding mask；条件清零和中性加权均为本题自行提出的试验，不属于 P-RMF 原方法。

### 3.3 Q3：EMOE 预测与两级解释

Q3 冻结既有 EMOE checkpoint。三路 Conv1D 把 T/A/V 映射到 256 维，4 层、8 head 单模态 Transformer 得 `h_T,h_V,h_A:B×256`；Router 对原三模态对齐输入生成 `w_T,w_V,w_A:B×1`，`Σw=1`；加权和 `z=w_Th_T+w_Vh_V+w_Ah_A:B×256`，接 `B×3` 分类头与 `B×1` 回归头。

**模态级**并列报告 Router 融合权重与整模态遮挡导致的原预测类别概率下降，避免把内部权重直接叫作贡献率。**时间级**在每个模态中测试最多 4 个连续有效槽的窗口，遮挡后记录原类别概率变化 `Δp` 与强度变化 `Δr`，选模型最敏感窗口；Text 映射到词元和原文，Audio/Vision 报特征槽与**近似**时间/帧区间。用随机窗、原特征置零和其他样本特征替换来验证关键窗的预测敏感性。解释层不重训预测器；这些是模型证据，不等同于人类语义因果解释。

## 4. 对比、消融与失败案例

### 4.1 原公平双基线：后置特征遮挡协议，附件 2 valid

| 模型（3 seed 单模型均值） | Clean Acc / Macro-F1 / MAE / Pearson | 25 缺失场景均值 Acc / Macro-F1 / MAE / Pearson |
|---|---:|---:|
| EMOE | .6140 / .5818 / .6259 / .6119 | .6123 / .5814 / .6266 / .6086 |
| **P-RMF-E** | **.6392 / .6069 / .6025 / .6320** | **.6367 / .6033 / .6005 / .6297** |

P-RMF-E 在此统一协议下综合更好，因此作为当前 Q2 正式主干。这个旧协议让 Text 的完整上下文先进入 BERT，不能用其“缺失降幅小”说明附件 3 式文字缺失不困难。同一原模型、同一 valid 的 Text 中段 50%：旧后置遮挡 F1/MAE `.5869/.6027`，先 `[UNK]` 重编码后为 **`.4914/.6860`**；这是**输入协议诊断，不是模型退步**。

### 4.2 新协议消融：附件 2 valid，3 seed，Clean + 25 缺失场景

| 同一 `[UNK]` 重编码评价协议 | Clean Acc / F1 | 25 缺失场景平均 Acc / F1 | 主要观察 |
|---|---:|---:|---|
| 原 P-RMF-E | .6392 / .6069 | .6158 / .5815 | 统一参照 |
| 全样本 padding 清零 + 重编码训练 | .6268 / .5899 | .6147 / .5739 | 长 Text 缺失、MAE 改善；Clean 和平均分类退步 |
| 仅 Text 缺失时清零 padding | .6429 / .6063 | .6244 / .5758 | Acc 提高，Macro-F1 下降 |
| 再加独立 Text 缺失分类头 | .6355 / .6101 | .6115 / .5743 | 单种子曾提高，三种子整体未复现 |
| **条件清零 + 中性 CE 权重 1.5** | .6387 / .6012 | **.6180 / .5846** | 严重文字缺失收益；Clean 分类略降 |

候选在新协议 valid 的 Text 中段 50% 场景将 Acc/F1/MAE/Pearson 从 **`.5440/.4914/.6860/.5002`** 提高到 **`.5650/.5436/.6547/.5245`**。Neutral 召回 `.219→.442`，但 Negative `.733→.537`，说明它把部分错误转移到负类；不能写成所有类别都改善。原模型 Clean 中性召回约 `.380`，强情感回归还存在幅度向零收缩。缺失 embedding、覆盖率修正、轻量完整→缺失一致性此前也未获得稳定综合收益；这些是当前实现下的负结果，不是否定整个研究方向。

### 4.3 冻结后独立 test：新协议，附件 2 test 727 条

| 场景 | 模型 | Accuracy↑ | Macro-F1↑ | MAE↓ | Pearson↑ |
|---|---|---:|---:|---:|---:|
| Text 中段 50% | 原 P-RMF-E | .5571 | .4845 | .7839 | .4771 |
| Text 中段 50% | **中性加权候选** | **.5740** | **.5358** | **.7458** | **.5163** |
| 三模态中段 50% | 原 P-RMF-E | .5589 | .4966 | .7846 | .4734 |
| 三模态中段 50% | **中性加权候选** | **.5768** | **.5443** | **.7493** | **.5176** |
| 25 缺失场景均值 | 原 P-RMF-E | .6458 | .5871 | .6779 | .6194 |
| 25 缺失场景均值 | 中性加权候选 | .6471 | .5883 | .6681 | .6282 |
| Clean | **原 P-RMF-E** | **.6717** | **.6133** | .6464 | .6631 |
| Clean | 中性加权候选 | .6657 | .5977 | .6442 | .6631 |

**结论：**严重 Text 缺失的 Acc/F1 分别 `+.0169/+.0513`，三模态重缺失 `+.0179/+.0477`；25 场景平均只 `+.0013/+.0012`，Clean 为 `−.0060/−.0156`。总体 25 场景收益在三个 seed 上不同向，因此当前**不替换正式 P-RMF-E**，也不根据这次 test 再调参。附件 3 无标签，不能据其输出选择候选。

## 5. 目前最好成果与论文表述

| 用途 | 当前最好已测结果 | 论文中应怎样写 |
|---|---|---|
| Q2 完整输入分类工程成绩 | 原 P-RMF-E **三模型集成**，Clean valid Acc/F1 **.6593/.6287**；MAE/Pearson `.5873/.6418` | 是固定 checkpoint 的预测聚合，**不是**新网络结构，也不是附件 2 test 或可直接提交的压缩方案 |
| Q2 单模型正式主干 | 原 P-RMF-E，Clean valid Acc/F1 **.6392/.6069**；独立 test Clean **.6717/.6133** | 保留作正式主干；注明 valid/test、3 seed 单模型均值及缺失评价协议 |
| Q2 严重文字缺失专项 | 中性加权候选，独立 test Text 中段 50% Acc/F1 **.5740/.5358**，MAE/Pearson `.7458/.5163` | 明确是**局部缺失场景提升**，同时报告 Clean 与负类召回的取舍；暂不称整体最优 |
| Q3 预测与解释 | 冻结 EMOE，Clean valid Acc/F1/MAE/Pearson **.6085/.5827/.6287/.6088**；附件 4 **20/20** 条已有预测和解释 | Router 与遮挡敏感度分开报告。独立 donor 替换下关键窗相对随机窗的概率下降差约 **.112**，证明模型敏感性，不证明语义因果性 |

论文结构可据此写为：**问题定义和数据 → 两个模型的输入与模块 → Q2 连续缺失训练和双任务目标 → 同协议双基线 → `[UNK]` 输入链修正及轻量消融 → 冻结 test 的收益与代价 → Q3 Router、局部扰动和解释可靠性。**图表至少包含 Q2 旧/新协议分开的四指标表、Neutral/Negative 召回变化，以及 Q3 的 Router 与扰动贡献并列示例。Q3 音视频时段目前是槽位映射的近似值，论文不可写成已获得精确词级时间戳。
