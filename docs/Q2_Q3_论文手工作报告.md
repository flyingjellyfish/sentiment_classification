## 1. 赛题要求、问题关系与交付物

赛题以题方提供的 CMU-MOSEI 英文视频及特征为唯一情感数据来源。问题 1 从附件 1 原始视频建立三模态特征提取和时序对齐，并留下 100 条样本的可核验特征；问题 2 可使用附件 2 已处理特征研究**局部连续时间段**的 Text / Audio / Vision 信息缺失；问题 3 在三模态信息完整时同时给预测与可复核解释。三问从特征、鲁棒预测到解释递进，但赛题允许 Q2/Q3 使用附件 2，且没有要求两问共享同一个模型。论文必须清楚说明本工作 Q2 使用 P-RMF-E，Q3 使用 EMOE。[赛题原文](../复杂场景下多模态情感识别的数学建模与算法设计.docx)。

| 项目 | Q2：局部缺失鲁棒预测 | Q3：可解释预测 |
|---|---|---|
| 输入与学习 | 附件 2 train 学参、valid 选模型；连续时间窗可能在一个或多个模态不可用 | 附件 2 train 学参、valid 选模型；解释阶段使用冻结模型和完整输入 |
| 每样本必须输出 | Negative / Neutral / Positive 与连续强度 `[-3,3]` | 同左，加主要参考模态、各模态作用程度、Text 片段、Audio 时段、Vision 关键帧 |
| 必做分析 | 缺失模态类型、缺失率、位置、时长；基础性能、消融、错误归因 | 模态差异、主要模态局部证据可视化、典型样本解释卡、解释可靠性、错误归因 |
| 专项集 | 附件 3：30 条，无标签，只推理并汇总 CSV | 附件 4：20 条，无标签且有对应视频，只推理并汇总预测与解释 CSV |
| 指标 | valid 上 Accuracy、F1、MAE、Pearson | 同左；另外报告解释扰动敏感性与局限 |

赛题中连续强度 `y<0` 为负向、`y=0` **只**为中性、`y>0` 为正向；代码中的类 ID 是 `0=Negative, 1=Neutral, 2=Positive`，全部 train/valid 均满足 `class=sign(y)+1`。三分类与回归虽然标签相关，仍是题目要求的两个输出任务，不能把零值并到正类。**附件 3/4 无标签，不能计算其四指标，也不能用伪标签、预测分布调参或选模。**不得引入 MOSI、IEMOCAP 等其他情感数据；公共预训练 BERT 仅作为题目允许的特征编码器，不参与外部情感训练。

赛题最终附件要求两类专项 CSV、核心代码/权重/配置、问题 1 自生特征，总大小 **≤50 MB**，且材料不得含身份信息。这限制了多 checkpoint 集成作为最终提交形式；实验验证阶段的集成效果与实际可提交方案须分开说明。

## 2. 已核对的数据接口与缺失定义

### 2.1 统一特征版本和张量

当前 Q2/Q3 都使用附件 2 的 **`aligned_50.pkl`**，train / valid / test 各 **3395 / 728 / 727** 条。模型训练与选模只用 train/valid。每条特征：Text `50×768`，Audio `50×74`，Vision `50×35`；批量为 `B×50×D`。`text_bert` 是 `3×50` 的 BERT 词元 ID、attention mask、segment ID，**不是第四模态**。`raw_text` 用于文本摘录；ID 格式为 `video_id$_$clip_id`。有效长度 `L_i=sum(text_bert[i,1,:])`，内容槽位定义为 `1 ≤ t < L_i-1`，排除 `[CLS]`、`[SEP]` 与 padding。train 与 valid 的 `video_id` 无交集；valid 728 条来自 239 个视频 ID。音视频原始 NaN/Inf 置零后转 float32，文本转 float32。[读取和标签检查](../EMOE_repro/q2_aligned.py)、[mask 实现](../EMOE_repro/missing_protocol.py)。

统一观测 mask 记为 `M∈{0,1}^{B×3×50}`，内部模态顺序是 **L/V/A = Text/Vision/Audio**，`1` 表示当前特征可用。源特征中有效内容区内整行全零的 Audio/Vision 槽标为不可观测；padding 不计入缺失率分母，但现行模型 mask 把 padding 维持为 observed。代码实际未为 P-RMF-E 的文本 Transformer 提供 padding attention mask，这是后述方法限制。论文图表通常按 T/A/V 展示，必须写清楚与内部 L/V/A 的换位。

### 2.2 附件 3/4 的实查结果

附件 3 的 30 个 aligned pkl **没有 `text` 字段**，只有 `text_bert`。推理时用本机冻结 `bert-base-uncased` 把给定 token 编成 `50×768`，不得直接读取 `item['text']`。附件 3 的 Text 并非完全未缺失：27/30 条有效内容中有 `[UNK]`；同为 27/30 条有 Audio 内容零行。29/30 条三模态标识的缺失槽一致，其中包括 3 条无缺失；其余 1 条多一个视觉零槽。已完成的正式双基线入口按 `[UNK]` 和 A/V 零行构造已有缺失 mask，**不再次随机遮挡**。旧的早期 Q2 CSV 曾遗漏 Text `[UNK]` 的 mask，不应引用为正式附件 3 结果。[双基线附件 3 入口](../EMOE_repro/q2_dual_attachment3.py)、[专项 CSV](../EMOE_repro/results/dual_baseline_v2/attachment3_unlabeled_predictions.csv)。

附件 3 音频全部 50 个存储位置的零行比例为 **68.4%**，其中包含 padding，不能写成有效内容缺失率。逐样本在内容槽位内平均，Audio 零行 **20.6745%**、Vision 零行 **21.0912%**；Audio 内容零段数平均 **3.1667**。零槽未必逐条可证明都由题方后注入：只有少量附件 3 样本能与附件 2 精确配对。附件 4 有 20 个 pkl、对应视频和完整的三模态字段；其 13 号样本视觉特征 50 行全零，不能给它伪造视觉关键帧。附件 4 的 ID 与同名 MP4 已检查对应，但无原始帧到特征槽的精确时间映射。[Q3 输入审计](../EMOE_repro/results/q3/input_audit.json)。

### 2.3 实验中的人工连续缺失

训练时在每个 epoch、每条 train 样本上以 `0.8` 概率抽取一个连续内容窗口；窗口标称长度占该样本内容槽位的 `U(0.15,0.50)`，随机抽取 `T/A/V/T+A/T+V/A+V/T+A+V` 七种模态组合之一，并将对应 `M` 置零。两个 Q2 对照在**同 seed、同 epoch、同样本顺序**使用同一份预生成 mask。验证网格固定随机数，包含 Clean 及五种类型（T、A、V、A+V、三模态）的头/中/尾 30% 和中段 10%/50%，去重后为 **26 个条件、25 个缺失条件**。标称比例之外还记录`actual_new_missing_fraction`，因为被遮挡槽可能本来就是零行。**本协议的“缺失率”和“缺失时长”在同一有效长度下同步变化，当前实验不能独立估计两者的因果作用。**

## 3. 整体求解路线与目前实际 pipeline

```text
赛题附件2 aligned_50 / 同一 train-valid 划分
  → 读入 T(B,50,768), A(B,50,74), V(B,50,35), L(B), 类别(B), 强度(B)
  → 内容区 + 源零行识别，生成观测 mask M(B,3,50; L/V/A)
  → Q2: 同协议连续缺失训练 ─┬─ P-RMF-E：三路 token 编码→VAE proxy/不确定度→跨模态注入→双头
                            └─ EMOE：三路 Conv/Transformer→Router→动态融合→双头
  → valid 上复合分数选各自 best checkpoint → Clean/25缺失场景四指标、切片及资源评估
  → 附件3按其现有 UNK/零行推理，保存全部30条预测（当前有逐模型逐种子记录）

附件2 aligned_50 → 冻结已有的 Q3 EMOE checkpoint
  → 极性+强度+Router 融合权重
  → 每模态局部连续窗扰动 + 整模态遮挡
  → 文本 offset、音视频近似时间/帧映射 + 可靠性对照
  → valid 解释分析；附件4全部20条预测与解释 CSV
```

**不要在论文中画成一个训练好的统一 Q2/Q3 主干。**Q2 P-RMF-E 与 Q3 EMOE 目前共享数据接口和双任务目标，但权重、训练轮次、解释量不同。Q3 的 Router 来自 EMOE，并非 P-RMF-E 的 VAE 不确定度权重。

## 4. Q2：模型选择、模块和训练目标

### 4.1 为什么比较 EMOE 和 P-RMF-E

EMOE 原论文有模态特定专家、样本级 Router 和动态加权，便于 Q3 给出模态层解释；但它针对**局部缺失**并没有天然的缺失信息重建路径。P-RMF 原论文以不完整多模态输入、proxy 与不确定度融合为中心，更贴近 Q2 的鲁棒预测。实查后没有直接把两篇公开论文表格相比，而是在本题同数据和同预算下做了一次公平双基线。**P-RMF-E 是原作者核心结构的 E 题适配版，不是原论文完整训练流程逐行复现。**文献可见 [P-RMF 论文](https://aclanthology.org/2025.acl-long.1075/)与[EMOE 论文](https://openaccess.thecvf.com/content/CVPR2025/html/Fang_EMOE_Modality-Specific_Enhanced_Dynamic_Emotion_Experts_CVPR_2025_paper.html)。

### 4.2 P-RMF-E 的逐模块数据流（当前 Q2 主干）

以下维度从[适配代码](../EMOE_repro/prmf_e.py)和[固定配置](../EMOE_repro/P_RMF_upstream/configs/train_mosei.yaml)核对，内部顺序 L/V/A。表内“保留”指 P-RMF 作者方法的模块，“适配”指本题新增或改动。

| 模块与身份 | 输入 → 输出及实际方法 | 必要性/备注 |
|---|---|---|
| 输入及 mask（适配） | `T:B×50×768`、`V:B×50×35`、`A:B×50×74`、`M:B×3×50`；在缺失处将输入特征乘零 | 同时处理单路与多路局部连续缺失。默认主干以零表达缺失，mask 并未作为单独的可学习 token 进入 Transformer；显式 missing embedding 是另测变体。 |
| 三路 Linear + token Transformer（保留，长度适配） | 每路 `D_m→128`，再加位置编码及 **8 个可学习附加 token**；`B×(50+8)×128` 经 2 层、8 head Transformer，取前 8 个 token 得 `H_m:B×8×128`。Text 直接用已有 768 维表示，A/V 均改为 50 步。 | 将不同维数压到共同表征空间，并用 8 个汇聚 token 表示序列；跳过原入口重复 BERT。这里不是逐帧输出长度 50 的融合。 |
| 三个模态 VAE（保留） | 每个 `H_m:B×8×128` 经 2 层 Transformer 编码器，形成 `μ_m,logσ²_m:B×8×128`；重参数化和解码器重建 token。 | 利用不完整输入估计可用于代理融合的分布表征与不确定度。训练时完整输入只做 VAE/重建的目标，**不进分类/回归预测支路**。 |
| proxy 与不确定度权重（保留） | `σ_m=exp(0.5logσ²_m)`；在三模态维对 `exp(1/σ_m)` 归一化得到 `W:B×3×8×128`（实现中堆叠次序为 `3×B×8×128`）；`P=Σ_m W_m⊙μ_m:B×8×128`。 | 给各样本、token、通道自适应加权。`W` 是模型内部权重，**不是严格校准的缺失可靠性概率**。计算需注意极小/极大方差的数值范围。 |
| 梯度反转 + 跨模态注入（保留） | `GRL(P)` 与三路 `H_m` 进入 CrossmodalEncoder；每层以 proxy 查询 T/A/V，三路注意力输出分别乘广播后的 `W_m` 再与 proxy 残差合成，输出仍为 `B×8×128`。配置 `num_layers=4`，源码四次追加同一个 layer 对象，即**共享层参数、重复应用 4 次**。 | 原方法用 proxy 作为核心状态吸纳仍可观测的模态信息。GRL 前向为恒等，反传时反转 proxy 支路梯度。 |
| 双任务预测头（回归保留、分类适配） | 融合 token 均值 `z:B×128`；回归 `Linear(128,128)→ReLU→Dropout(.5)→Linear(128,1)` 得 `B×1`；新增 `Linear(128,3)` 得 `B×3`。 | 同时满足连续强度与三分类；评估/导出时强度截到 `[-3,3]`，训练时原始输出用于 L1。 |
| 训练辅助重建（保留） | 三路不完整 `H_m` 经 2 层 Transformer 重建器；与完整输入产生的对应 token 特征做 MSE。 | 为缺失条件提供完整输入监督。当前适配确保重建器参数进入 optimizer。 |

注意 `W` 的顺序在代码是 L/V/A；在图表中改成 T/A/V 时必须换位。P-RMF-E **没有 EMOE Router**，不能把 `W` 叫作 EMOE 权重。原 P-RMF 的随机散点/原数据设置已换为本题连续窗口；这一部分属于 E 题适配。研究者自己提出的缺失 embedding、覆盖率修正、一致性损失则属于后续实验，不是原论文主体。

### 4.3 EMOE 对照和 Q3 backbone 的数据流

[现有 EMOE 源码](../EMOE_source/trains/singleTask/model/emoe.py)输入 T/A/V 后，在缺失槽使用可学习的原维度 missing token。三路 `Conv1D` 分别以 Text `k=5`、Audio `k=1`、Vision `k=3` 映射到 256 维，位置长度分别为 `46/50/48`；每路经过 4 层、8 head 单模态 Transformer，当前默认取末时间位置，得 `h_T,h_V,h_A:B×256`。**不能把以前设计稿中的“有效长度 masked pooling”写成已采用主干；正式双基线 `StagedEMOE(control)` 关闭了该试验开关。**

对齐三路原输入沿通道拼成 `B×50×877` 并展平为 `B×43850`，Router 是 `43850→256→3`、温度 `0.1` 的 softmax。当前适配还给 Router 加了源缺失率的线性 bias（零初始化）；输出 `w:B×3`，内部顺序 T/V/A，`Σw=1`。采用 sum 融合：

`z_f = w_T h_T + w_V h_V + w_A h_A`，每个 `w_m:B×1` 沿 256 维广播，故 `z_f:B×256`。随后残差 MLP、原 `B×1` 回归头和 E 题新增的 `B×3` 分类头。三路单模态回归头 `h_m→B×1` 用于辅助目标，另有 EMOE 的蒸馏和平衡项。Router 权重表示**模型的融合分配**，不等于遮掉该模态会降低多少概率；Q3 会单独测后者。双基线 EMOE 约 **22.53M 参数**，Q2 P-RMF-E 约 **7.74M**。

### 4.4 损失函数和选模

设类别真值 `c_i∈{0,1,2}`、强度真值 `y_i∈[-3,3]`，两模型共用的双任务项是

`L_task = CE(s_i,c_i) + |r_i-y_i|`（对 batch 取均值），其中 `s_i∈R³` 是分类 logits，`r_i∈R` 是回归输出。训练时并没有用 `sign(r_i)` 强制改写分类结果，两头可能在某些样本上不一致，论文展示时应分别报出。

P-RMF-E 当前总损失为 `L_P = L_task + 0.1 L_rec + 0.5 L_proxy`。`L_rec` 是不完整 token 重建特征与完整输入 token 的 MSE；`L_proxy` 是源码返回的 `kl_loss`，内部含三路 VAE 重建/KL及模态分布之间 KL。论文中若写具体展开式，应按[源码](../EMOE_repro/P_RMF_upstream/models/generate_proxy_modality.py)逐项抄准，避免把这 `0.5` 项简写成“单一标准正态 KL”。EMOE 当前总损失为 `L_E = CE + L1 + 0.2 L_uni + 0.02 L_balance + 0.002 L_router + 0.02 L_distill`：单模态绝对误差按观测覆盖加权；Router 的训练目标按覆盖率与单模态回归误差构造并停止梯度；模态特征蒸馏由作者函数实现。[EMOE 目标实现](../EMOE_repro/q2_aligned.py)。**两模型的辅助损失不同，因此双基线是模型家族比较，不是只换一个融合层的严格消融。**

公平比较用种子 `1111/2222/3333`，每 seed 8 epoch，batch 16，AdamW `lr=1e-4`、`weight_decay=1e-4`、AMP、梯度范数裁剪 1.0；RTX 5060 Ti 16 GB。每个 epoch 在 valid 的 Clean 和 A/V 中段 30% 计算

`S = F1_clean + F1_AV30 + 0.25(Pearson_clean+Pearson_AV30) − 0.25(MAE_clean+MAE_AV30)`，仅保留 `S` 最大的 checkpoint。Accuracy 不单独参与选模；25 场景全网格在最佳 checkpoint 固定后评估，不对某个场景重选。这个复合选模是**本题比较协议**，不是 P-RMF 或 EMOE 原论文公式。[训练入口](../EMOE_repro/q2_dual_baseline.py)、[事前协议](../EMOE_repro/P_RMF_E双基线统一协议.md)。

### 4.5 新一轮 Q2 输入协议修正与轻量候选（自行适配，未晋升）

原后置遮挡先对完整词元序列 `u` 求冻结 BERT 特征 `B(u)`，再将缺失槽置零，形式为 `M⊙B(u)`。附件 3 的 Text 先在词元层发生 `[UNK]` 替换 `C(u)`，实际输入更接近 `M⊙B(C(u))`。由于 BERT 双向上下文会改变**未被遮挡位置**的特征，二者并不等价。本轮新协议在附件 2 train/valid 中按同一窗口生成 `C(u)`，保持原 attention/segment ID，经同一本地冻结 BERT 得到 `50×768`；缺失槽仍按观测 mask 置零。Audio `50×74`、Vision `50×35` 和模型内部 L/V/A 顺序不变。训练重建项中的完整 Text 目标仍用附件 2 原始 `text`；**没有新增情感训练数据**。[新实验入口](../EMOE_repro/q2_unk_reencode_experiment.py)。

在固定三 seed、8 epoch、batch 16、原缺失增强和第 4.4 节选模分数下，依次检查四种轻量处理：①Text 重编码训练并对**全部样本**的有效长度后 padding 特征清零；②仅在 Text 内容缺失样本清零 padding（`gated_pad`）；③在②上为 Text 缺失另设 `128→3` 分类头（`gated_split`，约加 387 参数）；④在②上只对训练时“Text 内容缺失且真实类别为 Neutral”的交叉熵加权 1.5（`gated_neutral_1.5`）。④的分类项可写作 `L_cls=Σ_i α_i CE(s_i,c_i)/Σ_i α_i`，其中满足上述条件时 `α_i=1.5`，其他时候为 1；总损失仍为 `L_cls+L_reg+0.1L_rec+0.5L_proxy`。1.5 是本轮固定的一个取值，未搜索多个系数。③④均是**本题自行尝试**，不是 P-RMF 原论文内容；④不增加网络参数。

注意，padding 清零**不等于**给 Transformer 添加 padding attention mask，位置编码与层偏置仍可产生响应。②④在 Text 完整时保留原 padding 输入规则；重编码后仍执行原观测 mask。所有候选和原基线在新协议的 Clean + 25 场景上用**相同样本、窗口及指标**比较。新协议候选只影响 Q2；Q3 的冻结 EMOE 和解释输出没有重训。[逐项设置与复现命令](Q2_UNK重编码与padding增量实验_20260924.md)。

### 5.5 其他探索实验与集成（与主干消融分开）

`deepseek_work` 还做了简化 Transformer 受控台、模态子集、损失变体、多段缺失、后处理、EBMC 部分机制和额外 6 seed P-RMF-E。简化台不是当前 P-RMF-E 或 EMOE：部分分支无显式位置编码并均值池化，不能用它断言真实连续缺失位置无关。多段生成器在所谓“55%–70% 高缺失”设置下实际新增遮挡远低于目标（例如三模态平均约 10.66%），因此不能写“高缺失增强已被否证”。有序分类试验也不是严格保证顺序概率的 CORAL 实现。EBMC 的单模态与部分 EMC/IMTD/两阶段探索仅是辅助实验，不是完整 EBMC 复现，更没有在 P-RMF-E 上显示已确认收益。[独立评审](Q2_Q3_pipeline独立评审.md)、[辅助实验目录](../deepseek_work/exp/)。

### 5.7 缺失输入链诊断：为何旧曲线高估文字鲁棒性

先**冻结原 P-RMF-E 三个 checkpoint、不重新训练**，对同一 valid 728 条和同一 mask 比较 `M⊙B(u)`（旧后置遮挡）与 `M⊙B(C(u))`（先 `[UNK]` 重编码）。Clean 输入没有缺失，两协议四指标相同；当 Text 缺失时，未遮挡词元的 BERT 上下文也改变。以下是三 seed 单模型均值，不能写成“新模型退步”：

## 6. Q3：解释性模型与证据计算

### 6.1 模型、输出和训练来源

Q3 冻结的是先前 EMOE 缺失增强训练后继续微调得到的单一 checkpoint `results/q2/refined/full.pt`；继续训练设置在[原报告](../EMOE_repro/results/q2/refined/report.json)：从 `augment.pt` 初始化、`lr=5e-5`、最多 5 epoch、最佳第 3 epoch。编码、Router、双任务头及训练损失属于第 4.3–4.4 节所述 EMOE 适配结构，解释模块**没有重新训练预测器**。Q3 不使用 P-RMF-E 的不确定度权重来冒充 Router。验证集 728 条作为有真值性能分析；附件 4 20 条仅推理。

### 6.2 模态级作用：两个含义不同的量

EMOE Router 对每条样本给 `w=(w_T,w_V,w_A)`、和为 1。`argmax(w)` 记录为 `dominant_router_modality`，可以写“**融合权重最大模态**”。为了独立量化**当前预测对模态特征的敏感度**，再仅遮挡一个模态可用内容槽位，其他输入不动，计算

`A_m = p_{ŷ}(x) − p_{ŷ}(x\setminus m)`，`ŷ=argmax_k p_k(x)`。

CSV 保留有符号 `A_m`，正值表示遮挡后原预测类别概率下降，负值是相反方向。展示用贡献度 `C_m=max(A_m,0)/Σ_j max(A_j,0)`，若分母不足 `0.005` 则记主要扰动模态为 `None`，避免强行给无明显支持证据的样本选主模态。**Router 融合权重 `w_m` 与扰动贡献度 `C_m` 不能互换，更不是人类语义上的因果贡献百分比。**

### 6.3 时间级重要性与原素材映射

对 Text 去掉 `[CLS]/[SEP]/padding`；Audio/Vision 去掉内容区全零槽。每个模态把可用槽位按最多 **4 个连续对齐槽**分窗 `W`。每次仅把该窗 `observed_mask` 置为缺失，让 EMOE 的 missing token 替代原特征，记录：

`Δp_{m,W}=p_{ŷ}(x)-p_{ŷ}(x\setminus W)`，
`Δr_{m,W}=r(x)-r(x\setminus W)`，
`S_{m,W}=max(0,Δp_{m,W})+0.1|Δr_{m,W}|/3`。

每模态取最高 `S` 的窗作为“该模型最敏感的局部证据”；同时存 `Δp` 和有符号 `Δr`，以免将反向证据误写成正向支持。Text 用题给 `text_bert` 的 WordPiece/offset 对齐回 `raw_text` 字符区间。Audio/Vision 可以准确给出**特征槽位索引**，但附件 4 没有逐词/逐帧时间戳；秒数和帧号是以视频时长乘“槽位在有效内容中的比例”**线性近似**，CSV 字段带 `approx_`，必须人工回看原 MP4。07、18 号文本达到 50 token 上限可能截断；13 号 Vision 全零，因此其视觉证据应留空。论文解释卡应写“近似时段/帧”，不能写成精确定位或直接声称摘录中的词造成了预测。[解释代码](../EMOE_repro/q3_explain.py)、[输出字段说明](../EMOE_repro/Q3_README.md)。

## 7. 关键方法学限制与后续验证方向

### 7.1 已完成：文字缺失模拟的协议差异及边界

旧主表用 `M⊙B(u)`，附件 3 更接近 `M⊙B(C(u))`。此前在 8 条 valid 上只发现**表示差**：重编码后未遮挡内容位置、CLS、padding 的平均绝对差约 **.198/.178/.467**。现在第 5.7 节已在全体 728 条 valid、三种子、同窗口上量到**预测差**：原模型 Text 中段 50% F1 `.5869→.4914`，MAE `.6027→.6860`；并已按修正输入链训练、评估候选。故这一步不能再列为“尚未验证”。仍未解决的是**外推边界**：训练和网格主要是单段缺失，附件 3 音频在有效内容区平均约 **3.17 个零段**，且该专项无真值；不能按其预测分布反复选模型，也不能把单段模拟称为完全复现题方缺失生成机制。[协议差异完整结果](Q2_UNK重编码与padding增量实验_20260924.md)。

### 7.2 已完成初步消融：padding 数值与可观测信息

原 P-RMF-E 未给文本 Transformer 传入 padding attention mask；valid 有 **17,772** 个文本 padding 槽，其 BERT 表示非零。第 5.8 节已经测了从头训练的“全样本 padding 特征清零”和“仅 Text 缺失时清零”：前者改善回归及部分严重缺失场景，但 Clean F1 降 `.0170`；后者 Clean/25 场景平均 Accuracy 各增 `.0037/.0086`，25 场景 F1 却降 `.0057`。只在旧 checkpoint 推理时清零出现更大掉点，不能拿它判断从头训练处理无效。**清零输入特征不等于 attention 层严格屏蔽 padding**；位置编码、偏置和 `[CLS]/[SEP]` 仍需研究。现在可继续考虑正确的 attention mask，但须作为新实验，不能写成已成功改进。

### 7.3 优先级 3：解释的语义和时间定位

Q3 现有证据证明模型敏感性，尚缺对原始语义与时间映射的充分核验。Text BERT 位置向量带上下文，扰动一个向量不等于删掉那个词的语义；Audio/Video 槽到秒/帧是均匀插值。后续可先对少量典型样本人工回看 MP4 与文字，标出对齐误差；若需要精确秒数，再增加词级时间戳或特征提取时间戳，重算解释卡。Router 最大与消融最大低一致，应把两种作用定义并列展示，而非强行融合成一个“真贡献”。

### 7.4 其他可选工作，尚非已取得创新点

下一轮若继续研究 Q2，应预先设定“Clean 不退、长 Text 缺失提高、负/中/正召回不过度转移、强度误差不升”的联合门槛，重点检查多段缺失、实际新增缺失率和回归幅度收缩。此前 embedding/coverage/consistency、全样本清零、条件清零、双分类头的负结果只说明**当前实现与预算下没有整体晋升证据**，并未否定整个思想类别。中性加权已在附件 2 test 做过一次独立检查，**不得再针对该 test 反复调 1.5 系数、选 seed 或选模型并继续称 test 独立**；后续开发只用 train/valid，新增独立数据评价的边界须单列。附件 3/4 仍只做无标签推理，不能用伪标签选模。Q3 则优先补原视频人工回查与时间戳核对，而不是把 Router 权重直接改名为贡献率。

6. **Q3 实验**：放 valid 四指标、Router/消融均值及 35% 一致性、Top 对随机/独立 donor 对照、至少 1–2 张逐样本解释卡；放附件 4 20 条汇总并注明无标签。
7. **专项交付核查**：附件 3 当前是 180 行逐模型种子记录，正式一行一样本 CSV **待冻结方案后生成**；附件 4 已有 20 行解释文件。提交前核查总 50 MB、权重/配置/代码可复现性及匿名要求。切勿把实验目录里的九模型权重全部当作可直接提交附件。
