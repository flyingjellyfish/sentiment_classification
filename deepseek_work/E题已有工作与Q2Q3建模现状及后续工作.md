## 4. 问题 2：建模现状

### 4.1 模型与协议（当前有效）

| | EMOE（对照） | P-RMF-E（主干） |
|---|---|---|
| 主体 | 三路模态专家 + Router 动态加权 + 单模态预测 + 蒸馏/平衡 | 三路 token Transformer + 3 个 VAE + proxy 不确定度加权 + 梯度反转 + 4 次共享权重跨模态注入 + 重建器 |
| E 题适配 | 已对齐连续特征；三分类头 + 强度回归头；显式缺失 mask 与 missing token；`StagedEMOE(control)` 关闭试验性模块 | 跳过重复 BERT，直收 Text 768；A/V 改 50 步；随机散点缺失→连续窗口；加三分类头；**把作者遗漏的重建器参数纳入 optimizer**（明确的代码修正） |
| 参数量 | 22,530,412 | **7,740,036**（约 34%） |
| 8 epoch 训练 | 65.2 s | 138.0 s |
| 峰值 CUDA reserved | 560.7 MiB | 276.0 MiB |
| 推理吞吐 | ~1494 条/s | ~969 条/s |

**统一协议要点**：只用 aligned_50 的 train/valid；每样本每 epoch 按 `seed + 1000003×epoch` 生成一份 mask，80% 概率注入一段连续窗口（占有效内容 15%–50%），7 类模态组合含三模态同段；两模型同 seed 样本顺序与 mask 完全相同；单一 checkpoint 由 `Clean F1 + AV30 F1 + 0.25(Pearson和) − 0.25(MAE和)` 选出；**从不使用附件 2 test 或附件 3/4 选模**。内部 mask 顺序固定 **Text/Vision/Audio**，对外 CSV 用 Text/Audio/Vision。

### 4.3 我从结果文件独立读出的规律（文档未强调或未说透）

**(a) 缺失场景常常比 Clean 更好——这是最重要的反常识发现。**
用 `scenario_mean.csv` 逐场景与各自 Clean 比 Macro-F1：

- **EMOE：15/25 个缺失场景 F1 高于 Clean**。最好的是 `audio_end_30%`(+.0048)、`audio_middle_30%`(+.0039)、`audio_middle_50%`(+.0032)。
- **P-RMF-E：8/25 个缺失场景 F1 高于 Clean**，但幅度都在 +.0033 以内。
- 两模型最差的都是 **Text 相关缺失**：P-RMF-E 在 `text_middle_50%` 掉 **−.0201**、`text_start_30%` 掉 **−.0171**。

**含义**：论文**不能写"缺失越多性能越差"**。正确的表述是"**缺失的影响取决于模态，Text 的连续缺失才有系统性损伤；音频/视觉的单模态缺失在本数据上落在噪声内**"。这也解释了为什么"缺失鲁棒性"很难做出显著增益——因为基线的缺失损伤本来就不大。

**(b) 多数单场景结论落在噪声内。**
各场景 ΔF1 绝对值多在 .003～.02，而 3 seed 的 F1 标准差是 .003～.018。25 个场景里唯一在配对 bootstrap 下**稳定显著**的是大类：

| 对比场景 | Acc | F1 | MAE | Pearson |
|---|---|---|---|---|
| clean | 显著 | 显著 | 显著 | 跨0 |
| A+V 中段 30% | 跨0 | 跨0 | 显著 | 跨0 |
| 三模态中段 30% | 显著 | 显著 | 显著 | 跨0 |
| 三模态中段 50% | 显著 | 显著 | 显著 | 跨0 |
| Text 中段 50% | 跨0 | 跨0 | 显著 | 跨0 |

**可宣称的强结论只有**：① P-RMF-E 的 **MAE 在所有场景都显著更优**；② **Clean 与三模态同段缺失**下 Acc/F1 显著更优；③ **Pearson 一律不显著**；④ **长 Text 缺失时 P-RMF-E 的分类优势消失**。

**(c) 视觉的"标称缺失率"系统性偏小。**
标称 30% 的视觉缺失实际只新增 **28.0%–28.4%**；标称 50% 实际只 **47.2%**（`vision_middle_50pct`）。原因是 85 条 valid 样本的视觉内容区间本来就是全零，遮挡没有新增作用。文本最准（标称 30%→实际 29.96%）。**报曲线必须同时报标称与实际新增率**，否则视觉/音频/文本三者的横轴不可比。

**(d) 位置效应的方向在两模型上一致。**
30% 缺失时 Text 都是"**开头最伤、结尾最轻**"（P-RMF-E F1：start −.0171 / middle −.0097 / end −.0067）；三模态同段同样（−.0109 / −.0039 / −.0030）。**这是可以写成规律的**，但只是分组观察，不能反推"句首承载更多情感词"。

**(e) 真实的共同瓶颈（比主干选择更有论文价值）。**

| 指标 | EMOE clean | P-RMF-E clean | P-RMF-E 三模态缺 50% |
|---|---:|---:|---:|
| 负类召回 | .696 | .728 | .707 |
| **中性类召回** | **.370** | **.380** | **.357** |
| 正类召回 | .697 | .726 | .745 |
| **\|y\|≥1.5 的 MAE** | **1.198** | **1.128** | **1.321** |

中性类召回只有负/正类的一半；强情感强度回归误差是总体 MAE（≈0.60）的**两倍**；三模态缺 50% 时 P-RMF-E 的极端强度 MAE 反而**比 EMOE 更差**（1.321 vs 1.252）。**"总体 MAE 更优"不能推广到每条强情感样本**——报告里已举出 `2S00zYaVrtc$_$10`（真值 −2.667，P-RMF-E 只给 −0.300）这样的例子。

### 4.4 已做过的创新与失败定位（全部未过门槛）

预设门槛：**3 seed 的 25 缺失场景平均 Macro-F1 提升 ≥ +0.005 且 MAE 不升**。

| 变体 | 种子 | Δ缺失网格 F1 / MAE | ΔClean F1 / MAE | 门槛 | 失败定位 |
|---|---:|---|---|---|---|
| 缺失位置 embedding | 1（筛查） | −.0070 / +.0005 | −.0050 / +.0023 | 未做 | 训练后 L/V/A embedding 范数 .052/.078/.044，显式信号没转成更好分类 |
| coverage 修正 U 权重 | 3 | −.0049 / −.0007 | −.0024 / −.0007 | **false** | 学出的 β≈−.00495/−.00494/+.00178 **接近 0 且符号不稳** |
| 完整→缺失轻量一致性 | 3 | −.0027 / +.0029 | −.0018 / +.0014 | **false** | 一个种子里三模态中段 30% 曾 +.0108，三种子平均转负；Clean 中性召回 .380→.406 但极端强度 MAE 1.128→1.152 |

**这是本轮盘点里最需要正视的问题**：三次尝试都是"加一点东西"，都失败，且失败方向一致（分类没涨、强度略退）。文档的判断是"应先用 train/valid 研究 Text 长段缺失、中性类别与强度收缩的共同瓶颈，再单独预设新假设"。**我同意这个判断**——真正的机会不在"再叠一个缺失模块"，而在 (e) 指出的中性类与强度收缩。

## 5. 问题 3：建模现状

### 5.1 方法

**没有另训解释模型**，冻结 Q2 的 EMOE checkpoint `results/q2/refined/full.pt`（注意：不是 P-RMF-E）。解释分三层：

1. **模态层**：Router 输出 `w_Text/w_Vision/w_Audio`，`argmax` 记为 `dominant_router_modality`。文档明确声明**它是融合分配权重，不等于因果贡献**。
2. **时间层**：按最多 4 个连续对齐槽分窗，逐一把一个窗的 `observed_mask` 置假（模型按训练时的缺失 token 处理），记录 `Δp = p_ŷ(x) − p_ŷ(x∖W)` 和 `Δr`；每模态取 `max(0,Δp) + 0.1|Δr|/3` 最高的窗。文本窗用 BERT offset 精确截取 `raw_text`。
3. **整模态层**：单独遮挡一个模态的全部可观测槽，`A_m = p_ŷ(x) − p_ŷ(x∖m)`；`max(A_m,0)` 归一化得 `perturbation_contribution_*`；总正向下降 <0.005 时标 `None`。

### 5.2 验证结果（附件 2 valid，728 条）

| 条件 | Accuracy | Macro-F1 | MAE | Pearson |
|---|---:|---:|---:|---:|
| 原始预测 | .6085 | .5827 | .6287 | .6088 |
| **遮挡 Top3 关键窗** | **.5632** | **.5435** | **.6455** | **.5609** |
| 同模态同长度随机窗（3 次） | .5962–.6058 | .5716–.5809 | .6272–.6332 | .6037–.6125 |

忠实性：Top3 窗的原预测类概率平均降 **.2277**，随机窗 **.0127**；配对差 **.2150**，bootstrap95 **[.1994, .2318]**；**92.86%** 样本的 Top3 影响大于随机窗。

### 5.3 我独立复核后认为必须写进论文的四个"边界"

1. **选窗与验证同源**。Top3 窗是用单窗扰动挑出来的，验证又用同类遮挡比较——这只证明"选出来的窗对当前模型有可重复的敏感度"，**不能被解释为语义真值验证**。文档已诚实说明，但论文里必须用独立干预（换扰动方式/换窗长/留出验证子集）补一版。
2. **Router 与扰动解释严重不一致**。Router 均值 L/V/A = **.420/.339/.241**，整模态遮挡概率降 = **.0767/.0370/.0721**；两种"最大模态"只有 **35.0%** 一致。而且 **15 条无可用视觉**的样本里，仍有 8 条 Router 把 Vision 排第一。**两个数字必须并列展示，谁都不能单独当"主要参考模态"的答案。**
3. **局部与整模态符号常常相反**：valid 中"局部窗 Δp>0 但整模态 Δp<0"的有 Text **199/728**、Audio **195/728**、Vision **179/713**。多模态交互非加性 + softmax 饱和（附件 4 有 9/20 条最大类概率 >0.95）是主因。
4. **时间映射是近似**。附件只有 50 槽特征，没有词级时间戳；秒数/帧号用 `时长 × 槽位比例` 线性换算，列名都带 `approx_`。附件 4 的 **07、18 号达 50 token 上限**（原文分别有 15、9 个 token 被截断），估计更不可靠；**13 号视觉 50 行全零**，关键帧留空。

### 5.4 附件 4 的 20 条输出（我重算的分布）

- 极性预测：**Positive 10 / Neutral 4 / Negative 6**（这是**预测分布，不是准确率**）
- Router 主导模态：Text 12 / Vision 8（**Audio 一次都没有**）
- 扰动主导模态：Text 4 / Vision 5 / Audio 6 / **None 5**
- **两者一致的只有 6/20 条**
- 强度预测范围 [−2.637, 1.829]，其中 **8 条 |强度|<0.5**（强度向中性收缩的又一次体现）
- 典型弱解释样本：**16 号**（真值强负 −2.637）关键文本窗是 `"It's a"`；**10 号**是 `"(umm) And"`
