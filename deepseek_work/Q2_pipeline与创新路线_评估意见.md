# 对 Q2 pipeline、已试创新与后续规划的评估意见

> ⚠️ **本文档的部分建议已被 `Q2_实验验证报告.md` 与 `Q2_涨点与后续优化_最终报告.md` 的实验否证，请以实验报告为准。**
> 被否证的：
> (1) "概率平均优于多数投票" —— 实际相反（多 seed 池上多数投票稳定更优）；
> (2) "杠杆在强度保真，应上分布回归/有序损失" —— 三个候选都不如朴素基线；
> (3) "修好掩码分布就能测出鲁棒性" —— 多段同步增强无效；
> (4) "门槛设低了（对比单 seed）" —— 3 种子下 MDE≈0.020 Macro-F1，预设的 0.005 门槛本就不可达。
> 被证实的：
> (A) **多 seed 集成确实涨点**，26/26 场景一致为正，clean .6392→.6593（3 seed）/ .6525（9 seed）；
> (B) 原计划的四个 Q2 变体（含从未运行的 `mask_coverage`）**全部无增益**；
> (C) 在 aligned_50 预抽取上下文特征上"局部模态缺失"几乎不损失信息（A+V 全删仅 −0.025 Macro-F1，只留 `[CLS]` 仍有 0.399 F1），因此鲁棒性模块没有可回收空间。

> 结论全部由 `deepseek_work/` 下的脚本从已有结果文件重算得到，**没有训练任何新模型，没有改动其他 agent 的文件**。
> 脚本：`diagnose_q2_ceiling.py`、`ceiling_extra.py`、`test_deshrink.py`、`test_decision_fusion.py`、`test_ensemble_prior.py`

## 一、先把"64% 算不算低"用数据说清

### 1.1 相对于基线和任务，它不算低

| 参照 | Accuracy | Macro-F1 |
|---|---:|---:|
| 全猜多数类（Positive） | .4643 | .2114 |
| 按先验随机猜 | .3595 | — |
| **EMOE clean** | **.6085–.6140** | **.5827** |
| **P-RMF-E clean** | **.6392** | **.6069** |

64% 是多数类基线 **+17.6 个点**，Macro-F1 是多数类基线的 **2.9 倍**。训练集只有 **3395 条**（MOSEI 原论文用约 1.6 万条，是这里的 4.7 倍）。在这个数据规模下 MAE 0.60 属于合理区间；**Pearson 0.63 才是最弱的一环**（文献在 1.6 万条上约 0.70–0.75）。

### 1.2 但它的"错"高度集中在一个几乎不可分的带里

valid 728 条按真值强度分层：

| \|y\| 区间 | 条数 | 占比 | 分类头 Accuracy |
|---|---:|---:|---:|
| [0.00, 0.25) | 185 | 25.4% | **.4486** ← 低于多数类基线 |
| [0.25, 0.50) | 146 | 20.1% | .4932 ← 约等于瞎猜 |
| [0.50, 1.00) | 118 | 16.2% | .6186 |
| [1.00, 1.50) | 148 | 20.3% | .7500 |
| [1.50, 3.00] | 131 | 18.0% | **.7939** |

- **|y| < 0.5 占 45.5% 的样本，准确率 45–49%（≈瞎猜）；|y| ≥ 1.5 占 18%，准确率 79.4%。**
- 全部 285 个错误里，**61.8% 来自 |y|<0.5 的近中性带**，只有 22.5% 来自 |y|≥1.0 的清晰情感。

**这说明模型在"有明显情绪的样本"上是可用的，在"情绪很弱"的样本上基本等于没有信息。**

### 1.3 一个关键的正面纠正：中性类不是"被吞掉了"，是"分辨不出来"

| | 负 | 中 | 正 |
|---|---:|---:|---:|
| 真值边际占比 | .283 | .253 | .464 |
| 模型预测边际占比 | .268 | **.253** | .479 |

预测的中性占比与真值**完全一致（.253）**，但中性召回只有 **.446**。所以问题不是"中性被系统性判成正向"（那样边际占比会塌），而是**模型在中性样本上给出的排序没有区分度**。这一点会直接影响后面的方法选择——先验校正、类重加权这类"改边际"的手段**在原理上就无效**，实测也确实是零效果（见 2.2）。

### 1.4 错误构成：两种性质完全不同的错

| 错误类型 | 条数 | 占全部错误 | 占 728 条 |
|---|---:|---:|---:|
| 相邻类混淆（涉及中性） | 198 | 69.5% | 27.2% |
| **正负直接搞反** | **87** | **30.5%** | **12.0%** |

那 87 条正负翻转才是"模型真的错了"（很可能是否定、转折、对比、混合情绪）。**把 87 条砍掉一半，Accuracy 直接 +6 个点。** 这是比"缺失鲁棒"清晰得多的靶子。

### 1.5 天花板在哪（模拟结果）

用当前回归残差做重采样模拟（折内选阈值、折外评估）：

| 假设 | 三分类 Accuracy |
|---|---:|
| 残差不变（MAE≈0.63） | .6462 ± .0251 |
| 残差 × 0.75（MAE≈0.47） | .6951 ± .0255 |
| 残差 × 0.50（MAE≈0.31） | **.7646 ± .0230** |
| 残差 = 0 | 1.0000 |

另一条独立算法：若在 |y|≥0.5 上做到全对、|y|<0.5 全猜多数类，Accuracy = **.6676**（当前 .6085）。

**结论：64% 不是这座 pipeline 的真实数字，也不是它的天花板。**
- 已经在手、还没拿的一档：**多 seed 集成 → .6593 / .6287**（见第二节，免费）。
- 再往上的空间取决于"清晰情感那半"能不能做得更准：把 |y|≥0.5 从 .7254 提升到接近饱和，整体就能到 66–68%。
- 76% 那一档要求回归 MAE 减半，属于研究级目标，不是这次比赛该承诺的。

## 二、我实测的 5 个"免费杠杆"（1 个成功，4 个失败）

这一节是本文最有信息量的部分：**后处理层面已经没有空间了，改进必须发生在训练里。**

| 方案 | 做法 | 结果 | 判定 |
|---|---|---|---|
| **(A) 多 seed 集成** | 3 个已训练 checkpoint 多数投票 | **P-RMF-E: Acc .6392 → .6593（+2.01）、Macro-F1 .6069 → .6287（+2.18）**；EMOE: .6140 → .6264（+1.24） | ✅ **成功，且零额外训练成本** |
| (B) 回归平均 | 3 seed 强度取平均 | MAE .6025 → **.5873**，Pearson .6320 → **.6419** | ✅ 小幅但同向 |
| (C) 双阈值判类 | 用回归输出 + 在 valid 上 5 折交叉选阈值 | EMOE .6039 vs 分类头 .6085；P-RMF-E .6145–.6223 vs 分类头 .6360–.6415 | ❌ 不如独立分类头 |
| (D) 去收缩 | 反解回归的线性收缩后重新判类 | MAE 略降（.6287→.6146）但 Pearson 降；近中性带 MAE .409→.308，**极端带 .1.126→1.262 恶化**；判类 .5962 变差 | ❌ 说明收缩不是仿射标定问题，而是**异方差**的 |
| (E) 决策层堆叠 | 分类概率 + 回归值做 5 折 logistic 堆叠 | EMOE .6047（低于分类头 .6085）；P-RMF-E .5970–.6228（明显低于 .6360–.6415） | ❌ |
| (F) 先验 / logit 校正 | `p_k · (π_k^true/π_k^pred)^α` | α 从 0 到 1 全部 Accuracy = .6085（**完全无变化**）；5 折 .6063 | ❌ 印证 1.3：边际本来就对 |

**三条要带走的信息：**

1. **先把集成做了。** 现在的 64% 是单 seed 数字；论文里报集成的 .6593/.6287 更真实，也更像样。代价只是 3× 推理（训练已经跑过 3 个 seed，没浪费）。这也意味着**后续所有创新的对标基线必须换成 .6593/.6287**——之前三次消融都是单 seed 对单 seed，门槛设低了。
2. **失败的四项都是"改输出层的决策规则"，全都无效。** 因为分类头的排序质量已经优于任何从回归导出的规则。想涨分只能改**表征/回归质量**。
3. **(D) 的失败特别有诊断价值**：去收缩把近中性带修好了却把极端带弄坏了 → 预测误差是**随 |y| 增大而增大的异方差误差**（近中性 MAE .409，极端 MAE 1.126）。单一全局标定不可能同时修两头，**必须让模型自己输出不确定度**。

## 三、对现有 Q2 pipeline 的批评（按重要性排序）

**做得好的先说**：预注册协议、配对 seed/mask、实际新增遮挡率、不碰 test/附件 3/4 选模、配对 bootstrap 区间——这套方法学纪律比绝大多数参赛队强，**不要因为分数不高就动摇它**。

以下是问题：

### C1. 训练用的缺失分布和附件 3 的真实缺失分布不是一回事（最根本）

| | 训练增强 | 附件 3 实测 |
|---|---|---|
| 段结构 | **1 个连续窗** | **多个不连续短段**（01 号 2 段；02 号 8+ 段短零） |
| 模态耦合 | 单模态为主，7 类组合 | **audio 与 vision 零值位置几乎完全同步**（30/30 条都有 A/V 同段） |
| 占有效内容比 | 15%–50% | 逐样本 16–44 个位置（约 32%–88%） |

模型从没见过"多段 + A/V 同步"这种形态。**在部署分布上和训练分布不对齐的情况下，任何"缺失感知模块"都学不到该学的东西。** 这与 C2 一起，解释了三次创新为什么全部失败。

> 关于"不得利用附件 3 的缺失模式频率选参"这条自设规则：赛题原文禁的是用**无标签专项集的预测分布**去挑模型/阈值，而**设计增广分布族以覆盖合理部署形态**是常规鲁棒性做法。建议至少把"多段""A/V 同步"两种形态加进训练与评估网格——这不依赖附件 3 的任何统计量，也能用"覆盖并集"来论证合法性。若坚持严格口径，就**必须在论文里承认这是一个分布外测试**，并把附件 3 的结论降级为"接口连通性检查"，而不是"鲁棒性验证"。

### C2. 评估网格本身没有功效，测不出任何改进

用 `scenario_mean.csv` 逐场景与各自 Clean 比 Macro-F1：

- **EMOE：15/25 个缺失场景的 F1 高于它自己的 Clean**（最好 `audio_end_30pct` +.0048）。
- **P-RMF-E：8/25 个高于 Clean。**
- 各场景 |ΔF1| 多在 .003–.02，而 **3 seed 的 F1 标准差是 .003–.018**——同量级。

**结论：在 25 个缺失场景里，基线几乎没有可测量的退化，于是"鲁棒性改进"根本没有可回收的空间。** 这比"模块没设计好"是更根本的解释。

配对 bootstrap 下唯一稳健的只有：MAE（所有场景显著）、Clean 与三模态同段缺失的 Acc/F1。**Pearson 在所有场景都不显著。** 所以论文里能讲的鲁棒性故事其实只有一句：*"三模态同段 50% 缺失时 P-RMF-E 的 Macro-F1 比 EMOE 高 0.0274（区间 [0.0043, 0.0493]）"*，其余都要收着说。

### C3. 选模准则漏掉了唯一的真瓶颈

当前 checkpoint 分数是 `Clean F1 + AV30 F1 + 0.25(Pearson和) − 0.25(MAE和)`。A+V 中段 30% 恰恰是**损伤最小**的场景之一；而唯一有系统性损伤的 **Text 长段缺失**（P-RMF-E `text_middle_50pct` F1 −.0201）**根本没进选模准则**。选模眼睛是闭着的。

### C4. 没有做集成（白丢 2 个点）

见 2(A)。这条最简单，收益却比之前三次创新的总和还大。

### C5. 创新选错了轴

三次尝试都是"给模型加缺失感知能力"（缺失 embedding / 覆盖率校正 / 完整-缺失一致性）。但 **C2 说明缺失本来就伤不到模型**——没有 headroom 的轴上做改进，注定不显著。而 1.2/1.4 指出的**强度回归保真度**（收缩、极端样本 MAE 1.13–1.32、87 条正负翻转）才是可测的缺口，却一直没被当作创新主轴。

### C6. 规模与预算的隐忧

3395 条训练样本、8 epoch、batch 16、单一划分。valid 728 条上选模的噪声约 ±0.01–0.02，**和使用同一 valid 声明的效应量相同量级**。至少应该：把 valid 内的选择做成交叉验证（像我在 2 节里做的），或者扩到 5 seed。论文里所有"提升了 0.005"的结论都需要这个前提。

## 四、对三个已失败创新的判断

**建议：不要重启，至少不要在"缺失感知"这条轴上重启。**

失败定位已经在文档里写得很清楚，我补充一个统一解释：

- `coverage` 学出的 β ≈ **−0.00495**（≈0，且三种子符号不稳）——**模型自己给出的答案是"覆盖率不重要"**；
- `mask` 的 embedding 范数有 .05–.08（不是没学到），但没转成分类收益；
- `consistency` 把中性召回从 .380 提到 .406，却把极端 MAE 从 1.128 推到 1.152——**类别收益被回归代价抵消**。

三条都指向同一件事：**这个数据集上的缺失损伤小于模型本身的误差结构**。想验证鲁棒性方法，必须先造出"损伤显著"的评估面（C1 + C2 的修改）。否则再做十次也是同一结果。

## 五、我建议的后续工作重排

### Stage 0 —— 今天就能做，零训练（半天）

1. **实现 3 seed 集成**（先多数投票；再试概率平均，理论上更好）。重报 Clean + 26 场景的集成指标。
2. **把一切对标基线改为集成值**（.6593 / .6287 / .5873 / .6419）。这是后面所有 gate 的分母。
3. 顺手把"|y| 分层指标 + 错误构成（相邻 vs 翻转）"做成论文的固定分析表——它是本报告里最有解释力的一张图。

### Stage 1 —— 真正的主攻方向：强度保真（训练侧）

病灶已定位：**异方差误差 + 强度收缩**（近中性 MAE .409、极端 MAE 1.126；y~r 斜率 0.822，std 比 0.74）。对应的方法，每条都是单因素、都要预设 gate：

| 候选 | 机理 | 为什么可能有效 |
|---|---|---|
| **分布式回归头** | 输出 `[-3,3]` 上的分布（离散 bin + softmax，或 NLL 学 σ）而不是点估计 | 直接建模异方差；决策时用分布做 Bayes 判类，把 1.3/1.4 的不确定度用起来 |
| **有序结构** | 用 CORAL / 累积 logit 替代独立三分类头，或对相邻类做软标签 | **69.5% 的错误是相邻类混淆**，独立 CE 头浪费了标签的有序性 |
| **幅度感知损失** | 对 |y| 大的样本加权，或分位数/Huber 型损失 | 18% 的极端样本贡献了不成比例的 MAE |
| **数据效率** | EMA、强 dropout/weight decay、更长 epoch 配早停、或直接用小模型 | 文档已记录 EMOE 训练集 F1 .876→.976 而 valid .58：**严重过拟合**；而 7.7M 的 P-RMF-E 反而赢 22.5M 的 EMOE，说明**容量不是瓶颈** |

> Gate 建议：**valid MAE ↓≥0.02 且 Pearson ↑≥0.02 且 Accuracy 不降**，3 seed 且用集成基线比较。注意：**不要只拿 Accuracy 当验收**——1.5 节说明 Accuracy 的边际收益递减，而 Pearson/MAE 才是当前的分水岭。

### Stage 2 —— 把鲁棒性做对（前提是 C1+C2 先修）

1. **重新定义掩码过程** `M(·)`：参量化成（段数 k、段长分布、模态耦合 ρ）三元组，训练时覆盖 k∈{1,2,3}、含 A/V 同步形态。
2. **评估面加"硬区间"**：60–80% 缺失、多段、同步模态。只在硬区间上比较，因为那里才有信号（当前唯一稳健的三模态 50% 就是证据）。
3. **把退化度归一化**：报"相对自身 Clean 的归一化风险比"，而不是绝对 F1——这样才不受"某场景恰好比 Clean 好"的干扰。
4. 然后**再试一个最小模块**（比如缺失 embedding），用 Stage 0 的集成基线当门槛。若仍不过，就诚实写成负结果——那本身也是有价值的结论。

### Stage 3 —— Q3 对齐

把解释框架从旧 EMOE checkpoint 迁到 Q2 主干（P-RMF-E proxy 权重），并补独立忠实性（valid 半分裂选窗/验证、多尺度窗、用 logit margin 替代饱和概率）。

### 论文层面的建议

1. **把"局部缺失"形式化**：`M(·)` 作为时间轴上的随机掩码算子，明确段数/段长/模态耦合；定义**归一化鲁棒风险比**。这比"我们加了缺失 embedding"像数学建模。
2. **给出"歧义下限"这个结论**：极性标签 = sign(连续强度)，而 45.5% 的样本落在 |y|<0.5；用 1.2/1.5 的数据论证**三分类精度的上限由强度分辨率决定**，并给出量化（MAE→Accuracy 曲线）。这是一个真正的建模结论，也是对所有"为什么只有 64%"的正面回答。
3. **把双任务写成有序决策问题**，而不是两个并列的头。1.5 节已证明后处理无空间，所以这一节要写成"为什么在训练时就该耦合"，而不是"我们最后加了个阈值"。
4. **所有创新一律对集成基线比较**，否则门槛虚低。

## 六、一句话总结我的看法

> **64% 是被低估的数字（集成后 65.9%），但不是被误解的数字（任务本身在 |y|<0.5 上有硬性歧义）。**
> 现有 pipeline 的方法学纪律很好，但**创新用错了轴**：在"缺失本来就伤不到模型"的地方加了三次模块，而把真正可测的缺口——强度回归的收缩与异方差、87 条正负翻转——留在了原地。
> 后续正确的顺序是：**先集成 → 再攻强度保真 → 最后才修掩码分布重做鲁棒性。**
