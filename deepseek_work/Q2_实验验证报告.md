## 0. 一句话结论（与上一轮意见相比有重要修正）

我上一轮的核心建议是"**杠杆在强度保真，不在缺失模块**"。**实验否掉了这个建议**：分布回归、有序分类、幅度加权三个候选全部没有超过朴素基线，而作为负对照的"缺失 embedding"反而是四个变体里表现最稳的。

真正被实验支持的是一个更根本、也更有价值的结论：

> **在附件 2 的 aligned_50 预抽取特征上，"局部模态缺失"几乎不构成一个真问题。**
> 文本是 768 维**上下文级** BERT 表示，单个位置已编码全句信息：**遮掉全部内容槽只掉 0.040 Macro-F1，只留 `[CLS]` 一个位置仍有 0.399（clean 为 0.603）**；**把 Audio+Vision 整个删掉只掉 0.025**。
> 所以任何"缺失鲁棒性模块"都没有可回收的空间——这统一解释了仓库里三次失败创新、我的四个失败变体、以及我的掩码修正也失败。
>
> 同时这条 pipeline 是**方差主导**的：同一变体换随机种子带来的波动（组内 SD 0.012–0.018）是变体间差异（组间 SD 0.004–0.007）的 **2–4 倍**；3 种子下的最小可检出效应 MDE ≈ **0.020 Macro-F1**，而所有"创新"的效应量都在 0.003–0.013。
> **唯一稳定可复现的杠杆是方差缩减**：多 seed 集成。

## 2. E1 —— 训练缺失过程 vs 附件 3 真实缺失（C1 成立）

| | 训练生成器 `epoch_mask()` | 附件 3 对齐版（30 条） |
|---|---|---|
| 每条模态的段数 | **100% 恰好 1 段**（276/276） | **均值 4.77 段**（范围 2–10） |
| 段长中位数 | **6 槽** | **1 槽** |
| 长度=1 的段占比 | 4.3% | **60.8%** |
| 长度≤2 的段占比 | — | 74% |
| 模态耦合 | 单模态为主（单模态 1189 / 双 1126 / 三 373） | **A/V 位置 IoU 均值 0.995，29/30 条完全同步** |
| 被遮占有效内容比 | 均值 32.4%，上限 50% | audio 68.4% / vision 68.7% |

**结论**：训练分布和部署分布的**过程**都不同——段数、段长分布、模态耦合、缺失率四项全不一致。我上一轮说"多段短段 + A/V 同步"是对的，但**遗漏了缺失率也差一倍**（68% vs 上限 50%）。

## 3. E2 + E7 —— 网格没有功效，pipeline 方差主导（C2 成立）

**E2：**
- 配对 bootstrap 的 95% 区间半宽 ≈ **0.023**（Macro-F1）；
- 25 个缺失场景的 |ΔF1| 均值 = **0.0043**，最大 0.0201 → **24/25 低于检出阈值**；
- 只有 `all_three_middle_30pct` 和 `50pct` 的 Acc/F1 区间不跨 0。

**E7：方差分解（5 变体 × 3 种子）**

| 指标 | 组内 SD（换种子） | 组间 SD（换变体） | 比值 |
|---|---:|---:|---:|
| Accuracy | 0.0182 | 0.0063 | 0.35 |
| Macro-F1 | 0.0124 | 0.0054 | 0.43 |
| MAE | 0.0135 | 0.0069 | 0.51 |
| Pearson | 0.0175 | 0.0038 | 0.22 |

**最小可检出效应（MDE ≈ 2.8·SD_within/√n）：**

| 种子数 n | Accuracy | Macro-F1 | MAE | Pearson |
|---|---:|---:|---:|---:|
| 3 | 0.0294 | 0.0201 | 0.0218 | 0.0283 |
| 5 | 0.0228 | 0.0156 | 0.0169 | 0.0219 |
| 8 | 0.0180 | 0.0123 | 0.0133 | 0.0173 |

**对照实际效应量**：P-RMF-E vs EMOE clean 为 +0.0252 F1（勉强可检出）；三个失败创新为 0.0070 / 0.0049 / 0.0027（**全部不可检出**）；25 场景均值 0.0043（不可检出）。

> **这就是"为什么所有创新都失败"的答案：不是想法不好，是效应量小于噪声底。** 反过来说，**我上一轮批评仓库"门槛设低了"这句话本身也不公平**——在 3 种子、728 valid 的条件下，门槛 (0.005) 本来就低于 MDE (0.020)，谁也过不了。

## 5. E4 + E10 —— 集成：唯一被证实的免费杠杆

### E4：P-RMF-E（仓库主干，3 个已有 checkpoint，重推理拿到完整概率）

| 聚合方式 | Accuracy | Macro-F1 | MAE | Pearson |
|---|---:|---:|---:|---:|
| 单 seed 均值（= 当前报告值） | .6392 | .6069 | .6025 | .6320 |
| **类别多数投票** | **.6593 (+.0201)** | **.6287 (+.0218)** | .5873 | .6418 |
| 概率平均 | .6442 (+.0050) | .6112 (+.0043) | .5873 | .6418 |
| 概率几何平均 | .6429 | .6101 | .5873 | .6418 |
| 2 seed（1111+2222） | .6484 | .6171 | .5858 | .6427 |
| 2 seed（2222+3333） | .6360 | .6075 | .5957 | .6339 |

- **多数投票显著优于概率平均**（.6593 vs .6442）。原因就是 E3 的 ECE = 0.236：概率平均被最自信的那个种子主导。**我上一轮建议"再试概率平均，理论上更好"是错的。**
- 3 seed 下 560/728（77%）样本三个种子预测一致；在不一致的 168 条上，单 seed 正确率仅 0.42–0.45，**集成把它抬到 0.458**——增益正来自这些分歧样本。
- 集成没有修好瓶颈：中性召回 0.364→0.380，`|y|≥1.5` MAE 1.087→1.109（略差），`|y|<0.5` Acc 0.450→0.438（略差）。**集成是方差缩减，不是能力提升。**

### E10：独立受控台复现（我的 ~3M 参数 2 层 Transformer）

| 场景 | 单 seed 均值 Acc | 多数投票 Acc | 概率平均 Acc |
|---|---:|---:|---:|
| clean | .6213 | **.6277 (+.0064)** | .6181 (−.0032) |
| text_middle_50% | .6154 | .6168 (+.0014) | .6154 |
| all_three_50% | .6099 | .6168 (+.0069) | .6168 |

**方向复现**（投票 ≥ 概率平均），**幅度更小**（+0.6 vs +2.0），因为我的模型过度自信度只有 0.10（EMOE 的 ECE 是 0.236）。**集成收益 ∝ 基模型的过度自信与种子多样性。**

**回归平均在两个台上都稳定有效**：P-RMF-E MAE .6025→.5873、Pearson .6320→.6418；我的台 MAE .5858→**.5665**、Pearson .6602→**.6808**。这是比分类集成更普适的免费收益。

## 6. E5 —— 我的 Stage-1 建议被否（重要负面结果）

受控台：H=128、2 层 Transformer、25 epoch、cosine、AMP，5 变体 × 3 种子，唯一变量是头/损失。

**clean（3 seed 均值）**

| 变体 | Acc | Macro-F1 | MAE | Pearson |
|---|---:|---:|---:|---:|
| base（CE + L1） | .6213±.0232 | **.6026±.0176** | .5858±.0050 | **.6602±.0080** |
| dist（分箱分布回归） | .6209±.0146 | .5910±.0029 | .5867±.0082 | .6502±.0177 |
| ordinal（CORAL 有序） | .6305±.0121 | .5894±.0017 | .5857±.0192 | .6519±.0234 |
| amp（幅度加权 L1） | .6163±.0093 | .5927±.0125 | .5987±.0071 | .6536±.0033 |
| missing_emb（负对照） | .6305±.0110 | .5976±.0063 | **.5798±.0096** | .6554±.0092 |

**配对种子差（clean，Δ vs base）**

| 变体 | ΔMacro-F1 | ΔMAE | ΔAcc |
|---|---:|---:|---:|
| dist | −.0116 ± .0185 (−.038/+.004/−.001) | +.0009 | −.0005 |
| ordinal | −.0132 ± .0172 (−.036/+.005/−.009) | −.0001 | +.0092 |
| amp | −.0099 ± .0078 (−.020/−.009/−.001) | **+.0129（更差）** | −.0050 |
| missing_emb | −.0051 ± .0114 | **−.0060（更好）** | +.0092 |

**结论**：
1. **分布回归 / 有序分类 / 幅度加权三个"强度保真"候选，没有一个超过朴素基线**；`amp` 甚至把 MAE 弄差了（与设计意图相反）。
2. **作为负对照的 `missing_emb` 反而是四个变体里最好的一个**（MAE 改进在 3 个种子里 2 个为负，是最一致的一个）。所以我说的 C5"缺失模块不会有用"**也没有被支持**。
3. 所有 |Δ| ≤ 0.013，而配对 SD 是 0.008–0.019 → **全部落在噪声内**。这个受控台只能排除**大**效应（≥0.02），不能分辨小效应。**我用来批评仓库网格的理由，同样适用于我自己的这个实验。**

> 顺带一个重要副产品（见 E7b）：这个只花了 40 秒训练的 ~3M 参数朴素模型，**MAE (.5858) 和 Pearson (.6602) 都优于** 带 VAE/proxy/跨模态注入/重建的 P-RMF-E（.6025 / .6320），Acc 只低 0.018。**架构复杂度不是这里的杠杆。**

## 8. E8 + E9 —— 真正的答案：局部缺失在 aligned_50 上几乎是伪问题

### E8：模态敏感性（3 seed 均值，Macro-F1）

| 遮挡 | Macro-F1 | Δ vs clean |
|---|---:|---:|
| clean | .6026 | — |
| **Text 全部删除** | **.1862** | **−.416** |
| Vision 全部删除 | .5835 | −.019 |
| Audio 全部删除 | .5902 | −.012 |
| **Audio+Vision 全部删除** | **.5773** | **−.025** |
| 三模态全部删除 | .1685 | −.434 |
| Text 中段遮 25% | .5980 | −.005 |
| Text 中段遮 50% | .5945 | −.008 |
| Text 中段遮 75% | .5814 | −.021 |
| Text 内容槽遮 100% | .5622 | −.040 |
| 多段同步高缺失 | .6019 | −.001 |

**读法**：
- **Text 是唯一关键模态**（全删 −0.416）；**A+V 全删只掉 0.025 Macro-F1** → 音视频信息基本被文本覆盖。
- **局部时间遮挡几乎免费**：文本中段遮 50% 只掉 0.008，遮 75% 才掉 0.021，把**全部内容槽**遮掉也只掉 0.040。

### E9：机制核实

- `content` 的定义**排除位置 0**（CLS）：728 条中位置 0 被标为 content 的样本数为 **0**；内容槽均值 23.59。
- 只保留 `[CLS]`（位置 0）、其余全遮 → **Macro-F1 0.3986**（clean 0.6026）。
- 只保留 content、丢掉 CLS/SEP → 0.5773（仅 −0.025）。
- 只保留前 5 / 10 / 20 个位置 → 0.4661 / 0.5247 / 0.5504。

**所以 `text_span_100pct` 之所以只掉 0.040，是因为它没遮掉 `[CLS]`；而单个 `[CLS]` 就值 0.399 F1。** 这说明 aligned_50 的文本特征是**上下文级**表示——每个位置已经通过 BERT 注意力编码了整句语义，因此"遮掉一段连续时间"移除的信息极少。

> **这是整轮验证最重要的发现，也把问题的性质改写了一遍**：E 题问题 2 要求"局部时段模态缺失下的鲁棒预测"，但在附件 2 这种预抽取的上下文特征上，局部缺失几乎不损失信息。**鲁棒性不是模型没做好，而是这个测试面上没有可鲁棒的东西。**

## 9. 修正后的建议（替换上一轮的 Stage 0/1/2）

### 立刻做（零训练，已实测）
1. **3 seed 集成**：分类用**多数投票**（不要用概率平均），回归用**强度平均**。P-RMF-E 上可得 **Acc .6392→.6593、Macro-F1 .6069→.6287、MAE .6025→.5873、Pearson .6320→.6418**。
2. **把论文的所有基线换成集成值**，并在方法里写明"集成是对 3 个种子预测的聚合"，这在赛题规则内、无泄漏。

### 论文层面（这才是提分的地方）
3. **把"局部缺失影响很小"写成正式结论，而不是缺口**。命题化：在句子级上下文特征表示下，时间轴上的局部遮挡只移除冗余信息；用 E8/E9 的数据给出三条支撑（Text 全删 −0.416 vs 局部 50% −0.008；只留 CLS 0.399；A+V 全删 −0.025）。
4. **给出"歧义下限 + 方差下限"的双重上界**：
   - 歧义：45.5% 的 valid 落在 |y|<0.5，该带 Accuracy ≈ 0.45–0.49（≈瞎猜）；完美分类 |y|≥0.5 的天花板是 **0.6676**。
   - 方差：3 种子下 MDE ≈ 0.020 Macro-F1；因此任何 <0.02 的"提升"都不应宣称。
   这两条合起来正面回答了"为什么只有 64%"。
5. **攻 87 条正负翻转**（12% 的数据、30.5% 的错误），而不是继续加鲁棒性模块。

### 如果一定要做出可测的鲁棒性效果
6. 换测试面：用 **unaligned_50**（audio/vision 500 步、有 `audio_lengths`/`vision_lengths`）或**原始信号**做遮挡，那里局部缺失才真的丢信息。附件 3 也有未对齐版本，接口是现成的。
7. 或者**整模态缺失**作为评测主轴（A+V 全删仍只掉 0.025，说明即使这样空间也有限；但 Text 缺失是硬的，可做"跨模态补全"的题目）。
